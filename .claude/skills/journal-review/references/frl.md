# Finance Research Letters (FRL)

- **Abbrev**: FRL (Financ. Res. Lett.); ISSN 1544-6123
- **Publisher**: Elsevier (ScienceDirect; Editorial Manager).
- **Tier**: Premier finance LETTERS journal. CiteScore 10.1, IF 7.1. High-impact, very high-volume (~2,200+ articles/yr). Below top-3 and below JBF/JFQA, but a respected, fast venue for short novel results.

## Scope
Concise letters in ALL areas of finance, broadly defined. Welcomes papers on replicability/lack thereof, transnational applicability, challenging methodological approaches, or methodological contingency of findings.
- **CRITICAL EXCLUSION**: "Single country replications of well-established results are not generally within the scope." Must be concise (<2500 words), clearly written, with new/preliminary/experimental results of interest to the broad finance community.
- **Fit**: one sharp, novel finding contributing to finance theory AND practice. Vol forecasting / VaR-ES / event studies fit under Forecasting / Risk / Market efficiency.

## Format
- **Length**: main text **≤2500 words HARD** (includes in-text citations + footnotes; EXCLUDES abstract, refs, tables, figures, captions/notes, acknowledgements, declarations, appendices/supplementary). Exceeding = desk-reject.
- **Abstract**: unstructured, **≤250 words**; stands alone; avoid refs.
- **Keywords/JEL**: 1-7 keywords (avoid multi-word "and/of"); JEL NOT required/mentioned.
- **Structure**: numbered sections (1, 1.1, 1.1.1…); acknowledgements as separate section before refs; CRediT; tables/figures ideally at END w/ "Insert Table 1 here" markers; separate title page.
- **References**: Elsevier author-date (Harvard); et al. for 3+; alphabetical-then-chronological; a/b/c for same-author-same-year; LTWA journal abbreviations; DOIs.
- **Figures/tables**: editable text/source (not images); freestanding notes; avoid vertical rules/shading; placed at end.
- **LaTeX**: elsarticle encouraged; editable .tex/.docx required (no PDF source); double-column only via LaTeX, Word single-column.

## Submission process
Editorial Manager. **$200 submission fee** paid during submission before review (non-refundable; forfeited on desk-reject; waived for ATS transfers). Required: title page, anon/main manuscript (.docx/.tex), separate Highlights file (filename has "highlights"), figures/tables as editable source, data statement, declarations (COI/funding/AI via declarations tool), CRediT. Cover letter explicitly required for RESUBMISSIONS (detailed letter + rejected version + highlighted changes); standard for first submission. Suggested reviewers not mentioned. Rejected → resubmit only as NEW submission + new $200 fee.

## Review model
Single anonymized (single-blind). Editor desk-screen (scope/style/plagiarism; desk-reject forfeits fee) → ≥1 reviewer → editor decision. One formal appeal/submission. First-round ~4 wk (SciRev indicative). Acceptance rate not officially published.

## Fees & OA
$200 submission fee (mandatory, non-refundable; waived via ATS). Hybrid: subscription free; gold OA APC USD 3,540 excl. tax (CC BY / CC BY-NC / CC BY-NC-ND); OACS "best price promise" may lower it.

## Distinctive requirements
1. **Highlights MANDATORY**: separate editable file (filename has "highlights"), 3-5 bullets, each ≤85 chars incl. spaces. 2. ≤2500-word main-text cap (counting in-text cites + footnotes). 3. $200 fee up front, forfeited on desk-reject — confirm scope/style fit before paying. 4. Data statement at submission. 5. Data Option C: deposit data in a repo + cite/link, OR explain why not. 6. Generative-AI declaration. 7. CRediT. 8. NO single-country replications of well-established results. 9. No PDF source; double-column only via LaTeX. 10. No structured abstract; no JEL; abstract ≤250 w.

## Pre-submission checklist (extends generic)
- Main text ≤2500 words (count in-text cites + footnotes; exclude abstract/refs/tables/figures/captions/acks/declarations/appendices) — verify w/ actual count.
- Highlights separate editable file ("highlights" in name): 3-5 bullets, each ≤85 chars incl. spaces (character-count each).
- Abstract unstructured ≤250 w, stands alone; 1-7 keywords.
- Editable source (.docx single-column or .tex; LaTeX may be double-column); NO PDF source; elsarticle if LaTeX; tables/figures editable text at end w/ "Insert Table X here", freestanding notes, no vertical rules.
- Refs Elsevier author-date: et al. for 3+, alphabetical-then-chronological, a/b/c, LTWA abbreviations, DOIs; full in-text↔list match.
- Scope: ONE sharp novel result (not a multi-result full paper); NOT a single-country replication; if replication-flavored, frame as cross-national / methodology-challenging / contingency-revealing.
- Position vs most recent literature; advances theory AND practice; novelty explicit in title/abstract/highlights.
- Rigor despite brevity: clear sample/period/source, correct lag/timing (no look-ahead), DM/HAC for forecasts, proper VaR/ES backtesting, seeds fixed.
- Self-contained tables/figures, no table+text duplication; claims not overreaching evidence.
- Data statement done; data deposited+cited (Option C) or justified non-availability; replication code/data ready.
- Declarations: COI, funding (use the required no-grant sentence if none), AI-use, CRediT.
- Budget $200 fee; confirm scope fit BEFORE paying (desk-reject forfeits it); corresponding author w/ full contact; decide subscription vs OA ($3,540).
