# Empirical Economics (EmpEcon)

- **Abbrev / ISSN**: EmpEcon (Empir. Econ.); ISSN 0377-7332 (print), 1435-8921 (online)
- **Publisher**: Springer Nature (SpringerLink; hybrid, supports OA). Submit via Editorial Manager.
- **Tier**: Second-tier applied econometrics (ABS/AJG 2, ABDC A, SSCI Q1/Q2 depending on year). General applied-econometrics outlet with broad coverage — a solid target when the paper is empirical/applied but lacks the methodological punch for JAE/JBES.

## Scope
Applied econometric research across all fields of economics: micro, macro, labor, health, development, finance, environmental. Emphasis on rigorous empirical methodology (proper identification, robust inference, replication-friendly) applied to substantive economic questions.
- **Fits**: applied time-series/panel econometrics, forecasting evaluation, empirical finance (esp. cross-market, volatility, risk), applied macro-finance, applied labor/health with clean econometric design. Special issues on methodological topics (DSGE, panel, machine-learning-in-econ).
- **Weak fit**: pure econometric methodology (→ JoE/JBES), narrow finance-only methodology (→ JFinEc), theoretical papers with no data, single-country descriptive replications with no new question.

## Format
- **Length**: no hard cap; typical papers 25-40 pages; longer papers accepted if content warrants.
- **Abstract**: unstructured, ≤150 words typical.
- **Keywords/JEL**: 3-6 keywords + JEL codes required.
- **Structure**: IMRaD; single-anonymized (do NOT strip author names — Springer default for EmpEcon; verify latest policy at submission).
- **References**: Springer basic reference style (author-date); DOIs required where available.
- **Figures/tables**: editable; equations numbered; supplementary online appendix for extra tables/proofs.
- **LaTeX / Word**: both accepted; Springer provides LaTeX template (`svjour3`).

## Submission process
Editorial Manager. **No submission fee**. Required: manuscript, abstract ≤150 w, 3-6 keywords + JEL codes, cover letter (short), data-availability statement, declarations (COI/funding).

## Review model
Single-anonymized (author names visible to reviewers). Editor screens → 1-2 referees → decision. First-decision time typically 3-6 months (estimate; unverified). Journal is receptive to well-executed applied papers that top-field journals may find too narrow.

## Fees & OA
No submission fee. Hybrid: subscription route free; gold OA APC USD 3,290 (Springer 2025 rate, verify live). Many institutions have transformative agreements waiving APC.

## Distinctive requirements
1. **Applied focus**: contribution is empirical, not methodological. Reviewers don't require a new estimator — they require a substantive economic finding produced by careful application of existing methods (or a mild methodological twist).
2. **Data-availability statement** required (Springer data policy).
3. **Replication package encouraged**, not mandatory; increasingly expected for time-series/panel forecasting papers.
4. Single-anonymized review — standard title block with authors visible.
5. Broad economic audience: writing should be accessible beyond the narrow methods sub-community.
6. **Cross-country / panel comparative work is welcome** — a natural fit for cross-asset or cross-market empirical finance papers.

## Pre-submission checklist (extends generic)
- Abstract ≤150 words, unstructured, no refs.
- 3-6 keywords + JEL codes on title page.
- Standard title block with authors + affiliations (single-anonymized — do NOT strip).
- Data-availability statement + code deposit plan (GitHub/Zenodo/Springer supplementary).
- Editable manuscript (.tex `svjour3` or .docx).
- Complete declarations (COI/funding).
- **Frame contribution as an ECONOMIC finding**, not a methodological one: "We document X about Y using Z" — not "We propose new estimator Z applied to Y."
- Econometric rigor: identification story clear, OOS design if forecasting, lagged signals (`signal.shift(1)`), DM/HLN/SPA + HAC, QLIKE = actual/predicted, cluster-robust or date-aggregated inference.
- Multiple-testing control (Reality Check/SPA/Romano-Wolf/MCS) for any "significant" claim across many alternatives.
- Robustness: multiple periods, alt specs, subsample stability, hyperparameter sensitivity.
- Position vs recent EmpEcon + adjacent applied journals (JAE, Journal of Applied Statistics, JBES); 2-3 concrete empirical contributions.
- Author-date refs + DOIs; supplementary appendix for extra tables/detailed derivations.
