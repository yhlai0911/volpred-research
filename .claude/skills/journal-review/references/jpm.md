# The Journal of Portfolio Management (JPM)

- **Abbrev / portal id**: JPM (iij-jpm). pISSN 0095-4918; eISSN 2168-8656. Editor: Frank J. Fabozzi. Founded 1974.
- **Publisher**: Portfolio Management Research (PMR; ex-Institutional Investor Journals / iijournals), part of With Intelligence.
- **Tier**: Top PRACTITIONER journal (flagship in portfolio management). NOT a top-3 academic outlet, NOT a quant-econometrics journal. ~400 submissions/yr, ~44 published (~11%).

## Scope
Directed PRIMARILY at investment professionals — CIOs, PMs, analysts, trustees, consultants. Mission: publish contributions that help them make the best decisions. Write for that audience in **plain English, minimal jargon, clarity + brevity**.
- **CRITICAL EXCLUSIONS**: NO retail-investor papers; NO highly-quantitative papers; NO real estate (incl. REITs). HARD GATE: "Manuscripts that have clearly been written primarily for an academic audience will be rejected at the preliminary review." Academics read it but are NOT the target audience.
- **Vol forecasting / GARCH** publishable ONLY if reframed around an institutional-investor decision (portfolio/allocation/risk-budgeting payoff), heavy math in appendix/online supplement.

## Format
- **Length**: target 4,000 words (excl. abstract/exhibits/refs); rarely <2,500 or >7,500. Detailed empirics + proofs → online supplement (length-exempt).
- **Abstract**: unstructured, non-technical, target **160 words**; NO refs; define acronyms.
- **Keywords/JEL**: BOTH keywords AND JEL codes REQUIRED (page 2 w/ abstract + highlights).
- **Structure**: practitioner narrative — Title (≤12 words, SEO keywords front-loaded); Abstract; three-item Highlights/Key Takeaways; Intro w/ roadmap paragraph; ≤3 heading levels; short Conclusion (no new material); footnotes (NOT endnotes; not for references); References after main text.
- **References**: Chicago Manual of Style 17th ed. AUTHOR-DATE (in-text + list); CMS governs style/grammar.
- **Figures/tables**: ALL called "EXHIBIT" (never Table/Figure); Arabic numbered consecutively; text must explain each; color ok but legible in B&W; tables 9pt+ Times New Roman, decimal-aligned, native Word (not pasted pictures/Excel); charts w/ underlying data (Excel tab per chart). Equations on separate lines, right-margin Arabic numbered, no trailing punctuation. **Underlying data for ALL exhibits required.**
- **LaTeX**: no journal class. .tex accepted but must ALSO submit fonts-embedded PDF. PMR PREFERS MS Word (equations in Equation Editor/MathType). Full mechanical conformance (8.5x11, 1-in margins, 12pt TNR, etc.) only at FINAL acceptance.

## Submission process
Editorial Manager (editorialmanager.com/iij-jpm). Page 1 = title/date/each author name + full contact + one-sentence role/affiliation + corresponding author. Page 2 = title/date/abstract/three highlights/keywords+JEL. Main text page 3. Required "Declaration of Submission" paragraph (read agreement; all coauthors aware; no institution requires public posting on SSRN/ResearchGate/Sci-Hub). Exclusivity: one PMR-family journal at a time + not elsewhere until decision; on acceptance remove ALL prior versions (incl. SSRN). No suggested reviewers mentioned.

## Review model
Editor screens (alone or w/ advisory board) → 1-2 reviewers. Desk-reject within ~2 weeks. Full review typically 12-16 weeks. ~11% acceptance. Blinding NOT stated (UNCERTAIN) — prepare an anonymizable manuscript to be safe.

## Fees & OA
NO submission fee. $500 fee if author WITHDRAWS after acceptance (per FAQ; figure reported, not re-verified). Primarily subscription; OA/APC option + amount UNCONFIRMED (verify w/ reply@pm-research.com if OA needed). Signed PMR copyright agreement required before publication.

## Distinctive requirements
1. PRACTITIONER framing HARD gate (academic-audience papers rejected at preliminary review); plain English, minimal jargon, brevity. 2. NO highly-quant, NO retail, NO real-estate/REIT. 3. THREE-ITEM Highlights/Key Takeaways (each 1-2 sentences, ≤40 words). 4. EXHIBITS naming (never Table/Figure); underlying data for every exhibit. 5. Abstract ~160 w, non-technical, no refs, acronyms defined. 6. Chicago 17th author-date refs. 7. Footnotes not endnotes; not for citations. 8. Declaration of Submission + remove from SSRN/ResearchGate on acceptance + one-PMR-journal-at-a-time. 9. Heavy math/proofs/empirics → appendix/online supplement (length-exempt). 10. Title ≤12 words, subject keywords front-loaded.

## Pre-submission checklist (extends generic)
- AUDIENCE TEST (highest risk): rewrite FOR a CIO/PM/consultant — lead w/ the investment decision + "so what" for an institutional allocator, not the econometrics. Reframe a vol/GARCH paper around a portfolio/risk-budgeting/allocation payoff or it desk-rejects as "academic".
- Topic-exclusion check: NOT highly-quantitative, NOT retail, NOT real-estate/REIT; push heavy derivations/proofs/exhaustive robustness to appendix or length-exempt online supplement.
- Length: main 2,500-7,500 w, 4,000 target (excl. abstract/exhibits/refs); trim methods density not results relevance.
- Abstract ~160 w, non-technical, zero refs, acronyms defined, written to hook a busy practitioner.
- Three-item Highlights/Key Takeaways, each 1-2 sentences ≤40 words, as practitioner takeaways.
- Rename every Table/Figure → "Exhibit N" (consecutive Arabic); text explains how to read each + points to key values; color exhibits legible in B&W; attach underlying-data file for every exhibit.
- Convert all citations + list to Chicago 17th AUTHOR-DATE; move citations OUT of footnotes (footnotes peripheral only; no endnotes).
- Title page: p1 title/date/author contacts/one-sentence role per author/corresponding flag; p2 title/date/abstract/highlights/keywords+JEL; main text p3 — confirm keywords AND JEL present.
- Declaration of Submission paragraph; no coauthor institution mandates public posting; not under review elsewhere (incl. non-PMR); ready to pull from SSRN/ResearchGate on acceptance.
- Final-acceptance format: MS Word preferred (Equation Editor/MathType); if LaTeX also submit fonts-embedded PDF; 8.5x11, 1-in margins, 12pt TNR, single-spaced.
- Substance: emphasize economic significance, implementability (turnover, capacity, transaction costs, real data vintages), realistic OOS backtests over significance fireworks; provide underlying data; pre-empt "too academic / not actionable" w/ an explicit practitioner-use section.
- Title ≤12 words, strongest subject keywords first (search visibility).
