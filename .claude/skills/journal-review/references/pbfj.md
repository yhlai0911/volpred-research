# Pacific-Basin Finance Journal (PBFJ)

- **Abbrev / ISSN**: PBFJ (Pac.-Basin Finance J.); ISSN 0927-538X (print), 1879-0585 (online). Bi-monthly since 1993.
- **Publisher**: Elsevier (ScienceDirect; Editorial Manager).
- **Tier**: Top-field / regional-flagship — leading specialized outlet for Asia-Pacific capital-markets research (ABDC A, ABS 2*, SJR Q1/Q2). CiteScore 7.4, IF 5.4. The premier venue when the empirical focus is Asia-Pacific. ~12% acceptance (approximate).

## Scope
Specialized forum for reliable academic research on capital markets within the Asia-Pacific region — "but excluding papers that only use US data". Primary emphasis on highest-quality EMPIRICAL financial economics. Champions "responsible science" (credible/reliable, useful/relevant, independent/unbiased) + rewards useful research addressing real-world problems.
- **Fits**: empirical studies of Asia-Pacific markets (China, Japan, Korea, Taiwan, ASEAN, Australia/NZ, India) — incl. vol/risk/derivatives, microstructure, behavioral, banking, governance, ESG. Vol-forecasting / VaR-ES / GARCH / high-frequency fit IF the setting is an Asia-Pacific market (TAIFEX, Nikkei, HSI, KOSPI).
- **Does NOT fit**: US-only data; purely theoretical w/o empirical anchoring.

## Format
- **Length**: no explicit cap (~30-45 pp double-spaced norm).
- **Abstract**: unstructured, **≤250 words**; stands alone; avoid refs.
- **Keywords/JEL**: 1-7 keywords; JEL NOT required (optional at most).
- **Structure**: unstructured w/ NUMBERED sections (1, 1.1, 1.1.1…); cross-ref by number; footnotes sparing + numbered; acknowledgements ONLY on title page; conventional intro/data/method/results/conclusion.
- **References**: Elsevier name-date (author-year/Harvard); alphabetical-then-chronological; a/b/c; LTWA journal abbreviations; DOIs; abstract refs given in full.
- **Figures/tables**: editable text (not images); numbered + cited; captions; near text or at end. No graphical abstract.
- **LaTeX**: elsarticle encouraged; editable source (Word/LaTeX) for typesetting; both accepted.

## Submission process
Editorial Manager. **Double-anonymized** — upload TWO files: (1) Title Page (names/affiliations/corresponding full postal+email/acknowledgements/COI if no separate file) + (2) Anonymized Manuscript. Separate editable Highlights file required. Declarations tool (COI/funding/AI-use). No explicit cover letter or suggested/excluded reviewers section (EM may still prompt). **$220 submission fee** during submission before review for unsolicited new manuscripts (waived via ATS).

## Review model
Double-anonymized. Editors assess suitability (desk-reject if out of scope — e.g. US-only data — or style non-compliant) → ≥1 reviewer → editor decision. COI recusal rules. ~39 d / ~5-6 wk to first decision, ~12% acceptance (approximate/unverified).

## Fees & OA
$220 submission fee (non-refundable, before review; waived via ATS). Hybrid: subscription free; gold OA APC USD 2,970 excl. tax (CC BY / CC BY-NC / CC BY-NC-ND); read-and-publish / "best price promise" may reduce.

## Pre-submission checklist (extends generic)
- Confirm the setting is an Asia-Pacific market and the paper is NOT US-data-only; lead abstract/intro with the Asia-Pacific contribution.
- "Usefulness" framing: state which real-world financial problem / stakeholder decision the result informs (responsible-science criterion), not just statistical novelty.
- Highlights file: 3-5 bullets, each ≤85 chars incl. spaces, separate editable file ("highlights" in name) — count chars.
- Double-blind: separate Title Page + fully anonymized manuscript; remove "our prior work" self-cites, author names in acks/footnotes, identifying metadata.
- Abstract unstructured ≤250 w, self-contained, refs avoided (or full-cited).
- 1-7 single-word English keywords; do not rely on JEL.
- Budget + pay non-refundable $220 fee.
- Refs Elsevier name-date, alphabetical+chronological, LTWA abbreviations, DOIs; in-text↔list reconcile.
- Add generative-AI declaration before refs if AI used; complete COI + funding declarations tool.
- DAS + data sources/period/sample size + clearly lagged signals (pre-empt look-ahead); self-contained replication package.
- Methodology rigor: formal tests (DM/HLN, HAC, bootstrap; QLIKE actual/predicted; cluster-robust SEs for pooled cross-asset); claim strength matches evidence.
- Format: editable tables/equations, numbered sections (1, 1.1, 1.1.1), sparing numbered footnotes, acknowledgements only on title page; elsarticle template + retain editable source.
