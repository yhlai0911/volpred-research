# Journal of Financial Economics (JFE)

- **Abbrev**: JFE
- **Publisher**: Elsevier (ScienceDirect); editorial ops run independently at jfinec.com via Editorial Manager.
- **Tier**: Top-3 finance ("trinity": JFE / JF / RFS). ~5-7% acceptance (secondary estimate).

## Scope
Leading peer-reviewed journal in financial economics + theory of the firm; highest-quality empirical, theoretical, experimental contributions.
- **Fits**: high-impact work with a clear economic mechanism + rigorous identification — asset pricing, intermediation/banking, corporate finance, governance, macro/behavioral/household finance, microstructure, financial econometrics motivated by a finance question.
- **Does NOT fit**: incremental/descriptive empirics, pure methods w/o finance contribution, practitioner notes, work w/o a credible economic story/identification, topics outside financial economics. Vol-forecasting fits ONLY with an economic contribution beyond a forecasting horse-race.

## Format
- **Length**: no hard cap; concision expected; online appendices appended to END of anonymous manuscript at first submission. Initial-submission formatting enforced: double-spaced, ≥12pt, ≥1-inch margins, English proofread.
- **Abstract**: unstructured, **≤100 words hard cap** (distinctive — very short).
- **Keywords/JEL**: ~2-6 keywords + JEL for the published format (verify on live ScienceDirect guide; initial anon PDF needs only title+abstract).
- **Structure**: unstructured; initial submission = single anonymous PDF (title+abstract+body+appendices, all anonymized).
- **References**: JFE author-date (Harvard/Chicago author-date); BibTeX at accepted stage.
- **Figures/tables**: embed in anon PDF at submission; individual files at accepted stage; Internet Appendices PDF-only (`<num>_Supplementary_Material_Internet_Appendices.pdf`).
- **LaTeX**: elsarticle.cls + BibTeX recommended (production/accepted stage); Word/Excel accepted. Initial only needs anon PDF meeting formatting rules.

## Submission process
Editorial Manager (no email). **THREE uploads**: (1) anonymous manuscript PDF (no author info/acknowledgments; title+abstract ≤100 w; appendices appended+anonymized); (2) separate title-page PDF (all authors/affiliations/emails); (3) single combined COI PDF for EVERY author (required even if nothing to disclose). Cover letter OPTIONAL — the ONLY channel to request a data/code exemption. **Submission fee US$850** initial (no fee for R&R). Data/code DOI required at resubmission/acceptance (papers ≥ Jul 1 2021).

## Review model
Double-anonymized. Editor-driven w/ heavy author-editor interaction. Full refund if no decision within 120 days (~4-mo target). Secondary: ~4-8 wk screen, ~12-20 wk to first decision, ~9.9-mo median to acceptance, ~5-7% accept (estimates).

## Fees & OA
**US$850 submission fee** (initial; $400 partial refund on desk-reject, max 4/author/yr; full refund if no decision in 120 d; reduced-fee submission code via jfinancialeconomics@gmail.com if eligible). Subscription route no APC; optional gold OA APC ~US$5,200-5,500 (2026, approximate — verify live).

## Distinctive requirements
1. 100-word abstract cap. 2. $850 fee w/ refund schedule. 3. Mandatory data+code sharing (≥ Jul 1 2021): upload data, programs, raw-to-final cleaning code, run instructions, OS/software versions to Mendeley Data; data/code DOI before publication; confidential data → runnable pseudo dataset (up to 2-yr embargo); code exemption flagged in cover letter. 4. Three-file submission (anon manuscript + title page + combined COI PDF). 5. Appendices at END of anon manuscript; supplementary PDF-only at accepted stage. 6. Accepted-paper ack footnote begins "Editor Name was the editor for this article." 7. Resubmit within 18 mo; concise point-by-point response w/ page numbers (rambling discouraged). 8. Journal may refuse publication for data/code non-compliance.

## Pre-submission checklist (extends generic)
- Economic contribution FIRST — lead with the economic/risk-mgmt implication, not QLIKE/DM gains; reframe forecasting horse-races.
- Credible identification (or transparent limits), full robustness, honest multiple-testing (Harvey 2016 / HLN / cluster-robust SEs).
- Anonymize ruthlessly: no names/acknowledgments/self-identifying cites; appendices anonymized + appended to end; identities only on title page.
- Abstract ≤100 words (count it): question, method, headline result, contribution.
- Formatting gate: double-spaced, ≥12pt, ≥1-inch margins, English proofread (else returned).
- Three uploads in EM: anon manuscript PDF + title-page PDF + single combined COI PDF (every author).
- Pay $850 fee (or reduced-fee code if eligible); budget for it.
- Replication package: data + programs + raw-to-final code + run instructions + software/OS versions for Mendeley; confidential → runnable pseudo dataset + cover-letter exemption.
- Add ~2-6 keywords + JEL for published format (verify live).
- JFE author-date refs (BibTeX + elsarticle at accepted stage) + DOIs.
- Plan 120-day clock + 18-mo resubmission window; keep response letters concise, point-by-point, w/ page cites.
