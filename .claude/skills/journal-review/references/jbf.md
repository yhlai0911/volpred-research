# Journal of Banking & Finance (JBF)

- **Abbrev / ISSN**: JBF (J. Bank. Financ.); ISSN 0378-4266
- **Publisher**: Elsevier (ScienceDirect; hybrid, supports OA). Submit via Editorial Manager.
- **Tier**: Top-field general banking-and-finance (ABS/AJG 3*, ABDC A*). Below top-3 (JF/JFE/RFS), a premier broad-scope field outlet — realistic target for rigorous empirical finance/econometrics.

## Scope
Theoretical AND empirical research across all major fields of finance and banking; emphasis on implementation and on empirical/applied/policy-oriented work in financial institutions and markets; aims to improve communication between academics and policymakers/operational decision-makers.
- **Fits**: bank risk, intermediation, microstructure, asset pricing w/ institutional angle, risk mgmt (VaR/ES), volatility forecasting, derivatives, regulation, systemic risk, international finance, ESG/climate.
- **Weak fit**: pure macro, pure math-finance w/o empirical/institutional content, narrow corp-finance (→ JCF), methods w/o finance application (→ econometrics journals).

## Format
- **Length**: no official word/page cap (field norm ~30-50 pp double-spaced). The ~50-page figure circulating online is NOT in the current guide.
- **Abstract**: unstructured, **≤150 words hard cap** (not 200); no refs; no non-standard abbreviations.
- **Keywords/JEL**: 1-7 keywords; JEL not officially required but conventional — include 3-5 on title page.
- **Structure**: unstructured IMRaD norm; fully ANONYMIZED main file (double-blind); separate title page file; generative-AI declaration as titled section before references if AI used.
- **References**: no strict style at submission (house style = author-date Harvard applied at proof); submit clean consistent author-date Harvard + DOIs.
- **Figures/tables**: editable text (not images); equations editable & numbered; appendices A/B…; no graphical abstract.
- **LaTeX**: elsarticle encouraged; editable source required (.tex/.docx), PDF not acceptable as source; Word single-column; double-column only via LaTeX.

## Submission process
Editorial Manager. **Submission fee USD 350** (non-refundable, paid before review; resubmitted rejected paper = new fee; ATS transfer = no second fee). Required: anonymized manuscript, separate title page, abstract ≤150 w, 1-7 keywords, Highlights file, data-availability statement, declarations (COI/funding/AI/CRediT via declarations tool). No suggested reviewers requested; no formal cover letter for new submissions (cover letter + response required only for resubmission/appeal).

## Review model
Double-anonymized. Editor desk-assessment → ≥1 reviewer → editor decision. Appeals allowed (different managing editor + independent referee). ~2-3 mo to first decision, ~10-15% acceptance (indicative/unverified).

## Fees & OA
Submission fee $350 (mandatory, non-refundable). Hybrid: subscription route free; gold OA APC USD 3290 (excl. tax). Research4Life waivers / institutional agreements may reduce APC.

## Pre-submission checklist (extends generic)
- Abstract ≤150 words, unstructured, no refs/abbreviations (count it).
- Highlights separate editable file (filename has "highlights"), 3-5 bullets ≤85 chars each.
- Manuscript fully anonymized (names, affiliations, acknowledgements, funding-identifying text, "our prior work" self-cites); title page SEPARATE; 1-7 keywords + 3-5 JEL.
- Data Option C: deposit data+code in repo (Mendeley/Zenodo/ICPSR) and cite/link, OR explicit non-availability statement; data-availability statement included. (Self-contained replication package satisfies this.)
- Editable source (.tex elsarticle or single-column .docx) — never PDF; tables/equations editable text.
- Pay $350 fee in EM; complete declarations tool (COI/funding/AI/CRediT).
- Fit/framing: lead intro with a banking/finance question + POLICY/institutional relevance.
- Econometric rigor: correct OOS design, lagged signals, DM/HLN+HAC, QLIKE actual/predicted, proper VaR/ES + Basel calibration.
- Robustness: multiple periods incl. crisis/bear, alt specs, subsample stability, threshold sensitivity (dedicated section).
- Multiple-testing/data-snooping control (Reality Check/SPA/Romano-Wolf); no "only/unique" w/o re-verifying current table.
- Position vs recent JBF + top-finance; 2-3 concrete contributions; claim strength matches evidence.
- Author-date Harvard refs + DOIs, full in-text↔list match; verify all stats reproducible from code.
