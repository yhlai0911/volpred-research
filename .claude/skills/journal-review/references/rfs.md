# The Review of Financial Studies (RFS)

- **Abbrev**: RFS. eISSN 1465-7368; pISSN 0893-9454. EiC: Itay Goldstein. Monthly.
- **Publisher**: Oxford University Press for the Society for Financial Studies (SFS).
- **Tier**: Top-3 finance ("trinity"). JIF ~7.6, CiteScore ~9.8, SJR Q1. ~8.1% acceptance.

## Scope
Major forum for significant new research in financial economics; balances theory + empirics; interprets finance broadly incl. finance-economics interface. Selection emphasizes quality/importance, not technical complexity.
- **Fits**: rigorous, novel, well-identified asset pricing, corporate finance, intermediation/banking, microstructure, behavioral, household, international, FinTech, climate; empirical + theoretical.
- **Does NOT fit**: already published/accepted elsewhere; simultaneous submission; incremental work; pure replication w/o new insight; English so poor it burdens referees (desk-reject ground). Working-paper/SSRN posting is fine.

## Format
- **Length**: no overall cap but mechanically governed — submitted PDF **double-spaced, ≤28 lines/page, font ≥11** (violations returned unreviewed). Internet appendix inside the same PDF.
- **Abstract**: unstructured single paragraph, **≤100 words hard cap** (commonly violated → returned).
- **Keywords/JEL**: JEL codes used (scope organized around JEL); enter keywords + JEL in portal (e.g. G11/G12/G14).
- **Structure**: no mandated template; single anon manuscript PDF (title, abstract, body, refs, internet appendix labeled) + separate title-page PDF. Remove acknowledgments / identifying text (double-blind); self-cites in third person.
- **References**: author-date (Harvard), full alphabetical list; consistency > exact punctuation at submission.
- **Figures/tables**: embedded in the single PDF; **each figure needs ALT TEXT under its legend** (accessibility, enforced); self-contained tables w/ notes, SEs, significance.
- **LaTeX**: accepted, no mandatory class at submission (clean double-spaced, ≤28 lines/pp, ≥11pt PDF from any source). OUP formats at production.

## Submission process
SFS/RFS Editorial-Express portal (rfssfs.org / sfs.org "Submit a Paper"), integrated w/ SFS membership (first-time users since 10 Jun 2025 reset password). Non-refundable submission fee (tiered). Upload two PDFs: anon manuscript (internet appendix inside) + separate title page. Step 4: affirm Code & Data Sharing Policy compliance + request exemption there or in cover letter. Cover letter mainly at resubmission (separate anonymous "Reply to R1" letters). May request referees to avoid (not guaranteed). Declarations: sole-submission/no-prior-publication, COI, code/data ack. Resubmit within 18 mo.

## Review model
Double-blind (full anonymization, third-person self-cites). Desk screen first (~30-40% desk-rejected, partial refund). Goal: decisions in 2-3 rounds. Median ~33 d / mean ~38 d to first decision (heavy desk-reject; full refereeing ~2-4 mo). **Speed guarantee**: fee refunded if first decision > 120 days.

## Fees & OA
Non-refundable submission fee by income tier/membership: High-income SFS member $400 / nonmember $460; Middle-income member $260 / nonmember $320 (all coauthors must qualify); Low-income waived. Appeals $860. Desk-reject partial refund $200 (high) / $130 (middle); full refund if first decision > 120 d. Conditionally accepted + first-round invited dual submissions: fee waived. SFS membership → discount. Hybrid OUP: optional OA (CC BY / CC BY-NC / CC BY-NC-ND) w/ APC (exact RFS figure unconfirmed — verify on OUP); subscription route no APC.

## Distinctive requirements
1. **Code & Data Sharing Policy** (conditional acceptances ≥ 1 Oct 2025): reproduction Package = README + data-availability statement (Social Science Data Editors template v1.1) + raw+analysis data + all code/dependencies → deposited in RFS Harvard Dataverse; RFS Data Editors verify reproduction in a VM; code + replication report hosted in RFS GitHub. Confidential data → synthetic/pseudo data that runs the code. Exemptions requested IN COVER LETTER AT INITIAL SUBMISSION (propose withholding period); editor decides; noted on published paper. 2. 100-word abstract cap. 3. Double-spaced, ≤28 lines/pp, font ≥11 (else returned). 4. Two-file anon submission (manuscript w/ internet appendix INSIDE + separate title page). 5. Figure ALT TEXT under each legend. 6. Resubmission reply docs labeled by referee number, anonymous. No graphical/structured abstract.

## Pre-submission checklist (extends generic)
- Anonymize fully: no names/affiliations/acknowledgments/funding/IRB; self-cites third person; scrub PDF metadata.
- Abstract ≤100 words (count it) — else auto-return.
- PDF double-spaced, ≤28 lines/pp, font ≥11; internet appendix EMBEDDED + labeled (not separate).
- Two-file package: anon manuscript PDF + separate title-page PDF (names/affiliations/emails).
- ALT TEXT under every figure legend; self-contained tables w/ variable defs + SEs + stars.
- Confirm sole submission + no prior publication/acceptance (SSRN ok); complete COI declarations.
- Acknowledge Code & Data Sharing Policy; pre-build reproduction Package (README + DAS template v1.1 + raw/analysis data + runnable code); confidential → pseudo data + cover-letter exemption w/ withholding period.
- Pay correct fee for tier/membership; consider SFS membership for discount.
- Substance: sharp first-order contribution; importance + identification over complexity; state what's new vs closest published work.
- Identification + robustness: clean design, credible causal/identification or well-specified theory, clustered/HAC SEs, placebos; pre-empt endogeneity + look-ahead/data-snooping.
- Engage RFS/JF/JFE literature; every empirical claim matched by reported evidence (no overclaiming).
- Complete consistent author-date refs + DOIs; clear English (poor readability = desk-reject ground).
