# Journal of Forecasting (JoF)

- **Abbrev / ISSN**: JoF (J. Forecast.); online ISSN 1099-131X; print 0277-6693. Co-EiCs: Ngai Hang Chan + Hans-Jörg von Mettenheim (from Jan 2025).
- **Publisher**: John Wiley & Sons (Wiley Online Library).
- **Tier**: Field journal — forecasting / applied time-series econometrics (ABS 3*). Below the general-finance top-3 and a notch below its IIF sibling IJF. CiteScore 5.1, IF 2.6, ~12% acceptance.
- **DO NOT CONFUSE** with (a) Elsevier's International Journal of Forecasting (IJF) or (b) MDPI's open-access "Forecasting" — three distinct journals.

## Scope
International, multidisciplinary; refereed papers on any aspect of forecasting — theoretical, practical, computational, methodological. Approaches from statistics, economics, psychology, systems engineering, social sciences welcome; business/government/technology/environment applications. PARTICULAR interest: modelling issues + relationship of forecasting systems to decision-making; new modelling concepts + practical application details.
- **Fits**: a vol-forecasting paper with a clear OOS forecasting contribution + rigorous evaluation (DM/MCS/QLIKE) + a methodological or applied-modelling angle. The forecasting contribution must be the SPINE.
- **Weak fit**: pure asset-pricing / hedging-utility w/o a forecasting-evaluation core; a model w/o OOS forecast comparison.

## Format
- **Length**: no fixed cap — "Free Format submission" (initial submissions not constrained by rigid formatting).
- **Abstract**: unstructured, required, in main document; NO explicit word limit stated (Wiley convention ~≤200-250 w — confirm at proof). Not structured/labelled.
- **Keywords/JEL**: up to SIX keywords; JEL NOT required (multidisciplinary).
- **Structure**: standard unstructured (free format). Main doc order: short keyword-rich title (NO abbreviations); full author names + affiliations (single-blind — NOT anonymized); Acknowledgements; Abstract; ≤6 keywords; Main body; References; Tables (title + footnotes); Figure legends (beneath each image + as a list in text). Separate Title Page w/ running title <40 chars + present-address footnotes.
- **References**: APA standard; at FIRST submission any consistent style ok (APA enforced by acceptance/revision).
- **Figures/tables**: separate files; at first submission single file OR separate ok; at REVISION figures/tables MUST be separate files; each table w/ title + footnotes; figure legends beneath each image + as a list; highest resolution.
- **LaTeX**: accepted — submit main file as "Main Document - LaTeX .tex File" + a "Main Document - LaTeX PDF" for review + support files as "LaTeX Supplementary File"; Word/PDF also accepted. No journal-specific class required for initial submission.

## Submission process
Wiley Authors / Research Exchange portal (authors.wiley.com/journal/for). NO submission fee. Free Format supported. Required: (1) editable manuscript (text+figures+tables, or separate) w/ abstract + figure/table legends; (2) **ORCID iD for submitting author (MANDATORY)**; (3) Title Page w/ coauthor details incl. affiliation + email each; (4) ethics/integrity statements — data-availability statement, funding statement, COI disclosure, ethics approval, permissions. No explicit cover letter or suggested reviewers required (brief cover letter stating fit/novelty good practice). Funding in Acknowledgments (Open Funder Registry). Preprints accepted (update w/ link to final article). iThenticate/CrossCheck on all submissions.

## Review model
**Single-blind** (reviewers anonymous; authors visible — do NOT anonymize). EiC desk-screen gate (sent to review only if meets quality/relevance; meaningful desk-reject; ~12% acceptance). In-house submissions handled by unaffiliated editors. **Median Submission-to-First-Decision = 20 days** (fast for the field). COPE core practices.

## Pre-submission checklist (extends generic)
- Frame the contribution as a FORECASTING result, not in-sample fit: lead with genuine OOS (expanding/rolling) evaluation + a clear forecasting question (EiC quality/relevance gate, ~12% accept).
- Rigorous forecast-eval tests: DM (w/ HLN/HAC small-sample correction), Giacomini-White, or MCS; vol uses robust loss (QLIKE canonical actual/predicted, or MSE) + report the proxy.
- Eliminate + document look-ahead: explicit signal.shift(1)/lag, target_end < forecast_origin for multi-horizon forward labels, matched lag for baseline vs proposed; state the real-time information set per origin.
- Benchmark vs strong standard baselines (random walk / AR / HAR-RV / GARCH-family / forecast combination), not strawmen.
- Concise UNSTRUCTURED abstract + UP TO SIX keywords; major keywords in title; remove all title abbreviations; running title <40 chars on a separate title page.
- Do NOT anonymize (single-blind): keep full author names/affiliations/emails in main doc + title page.
- Ethics/integrity statements: Data Availability Statement (data-sharing EXPECTED — right Wiley DAS template + code/data genuinely available for replication), funding statement (also in Acknowledgments, Open Funder Registry), COI disclosure, permissions.
- Register/attach ORCID for submitting author (mandatory).
- References ONE consistent style throughout (APA preferred; required by acceptance); verify DOIs/names/years — iThenticate runs on all submissions.
- Tables w/ title + footnotes; figure legends beneath each image + as a list; supply figures/tables as SEPARATE high-res files at revision; if LaTeX, upload .tex + compiled PDF + supplementary files.
- Report sample period + size (well above >=500-obs internal bar) + ≥1 OOS subperiod spanning a downturn; full reproducibility (seeds for bootstrap/MC/CV).
- Confirm fit: core = forecasting methodology or an applied forecasting model with decision-relevance — if the real contribution is hedging/utility or asset pricing w/o OOS forecast evaluation, target a general-finance journal instead.
