# Journal of Financial Econometrics (JFinEc)

- **Abbrev / ISSN**: JFinEc (J. Financ. Econom.); ISSN 1479-8409 (print), 1479-8417 (online)
- **Publisher**: Oxford University Press (Oxford Academic; hybrid, supports OA). Submit via Manuscript Central (ScholarOne).
- **Tier**: Top-field financial econometrics (ABS/AJG 3, ABDC A, SSCI Q1). Founded 2003 as the dedicated venue for econometric methods applied to finance — sits between JoE (pure methodology, cross-disciplinary) and JEmpFin (empirical finance, less methodology-heavy).
- **IF 2024**: 2.42 | **5-yr IF**: ~2.5 (estimate) | **Quartile**: SSCI Q1
- **URL**: https://academic.oup.com/jfec

## Scope
Rigorous econometric methods with strong financial applications. Time-series & panel methods for asset pricing, volatility, derivatives, risk management, market microstructure, high-frequency data, credit risk, network models in finance. Both new methodology AND high-quality applications of recent methods to important financial questions are in scope.
- **Fits**: GARCH-family estimation/testing, realized volatility measurement, jumps, VaR/ES backtesting theory, Bayesian financial econometrics, machine-learning-in-finance-econometrics, high-frequency market microstructure, factor-model estimation, quantile regression for finance.
- **Weak fit**: pure finance theory (→ JFE/RFS), pure economics with financial data window-dressing, empirical papers with off-the-shelf methodology and no econometric contribution (→ JBF/JEmpFin), applied papers without a data component.

## Format
- **Length**: **≤40 double-spaced pages typical** (soft cap stated in guide); longer papers must be justified. Online appendix encouraged.
- **Abstract**: unstructured, **≤100 words** (Oxford official page confirms "not more than 100 words" — tighter than most finance journals; count carefully).
- **Keywords/JEL**: 2-6 keywords + JEL codes required.
- **Structure**: IMRaD; anonymized main file (double-blind); separate title page; supplementary online appendix for proofs, extra simulations, additional tables.
- **References**: author-date; Oxford/JFinEc house style (Chicago-adjacent); DOIs where available.
- **Figures/tables**: editable; equations numbered; supplementary material as separate file(s).
- **LaTeX**: strongly preferred; OUP provides LaTeX template.

## Submission process
Manuscript Central (ScholarOne): http://mc.manuscriptcentral.com/jfec. **Submission fee USD 65** for non-SoFiE members (SoFiE members free; non-refundable even on desk-reject; verify developing-country exemptions at OUP). ## Review model
Double-anonymized. Editor + associate editor → 1-2 referees → decision. Reported first-decision time 3-6 months (estimate; unverified for 2025).

## Fees & OA
Submission fee USD 65 (non-members; non-refundable; SoFiE members exempt). Hybrid: subscription route free; gold OA APC USD 3,555 (OUP 2025 rate, verify live). OUP Read & Publish agreements waive APC for many institutions.

## Distinctive requirements
1. **Replicability review is a CONDITION of acceptance** (JFinEc explicit policy): "For empirical, experimental, and numerical papers, authors will be required to upload source files and relevant data files for editorial replicability review as a condition of acceptance, and the Journal withholds the right to reject papers if underlying data are not provided for editorial review without compelling justification."
2. **ORCID mandatory** at submission (OUP policy).
3. **≤40 double-spaced pages** soft cap — longer papers need justification.
4. Simulation study expected for any new estimator/test.
5. Application must have clear FINANCIAL motivation (not econometric methodology dressed in financial data).
6. LaTeX strongly preferred (math-heavy field).

## Pre-submission checklist (extends generic)
- Abstract ≤150 words, unstructured, no refs.
- 3-6 keywords + JEL codes on title page.
- Manuscript ≤40 double-spaced pages (main text); overflow → online appendix.
- Manuscript fully anonymized; title page SEPARATE; ORCID iD ready to submit.
- **Replication package COMPLETE at submission**: data + code that regenerate every table/figure. JFinEc's editorial replicability review will call this in — no compelling justification = rejection. Test from clean clone; README + fixed seeds + pinned env.
- Data-availability statement + code deposit plan (GitHub/Zenodo/Dataverse).
- **Frame contribution as financial-econometric**: what financial question motivates the estimator? What does the estimator reveal that off-the-shelf methods miss? Reviewers will grade this pairing.
- Simulation section (if new estimator/test): finite-sample size/power/coverage under multiple DGPs, comparison to closest competitor.
- Econometric rigor: correct OOS design, lagged signals, DM/HLN/SPA + HAC, QLIKE = actual/predicted, cluster-robust inference.
- Multiple-testing control (Reality Check/SPA/Romano-Wolf/MCS).
- Robustness: multiple periods incl. crisis/bear, alt specs, hyperparameter sensitivity.
- Position vs recent JFinEc + JoE + JEmpFin; 2-3 concrete contributions.
- Author-date refs + DOIs; supplementary appendix for long derivations/proofs.
