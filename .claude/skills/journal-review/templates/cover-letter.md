# Cover Letter Template (journal-agnostic)

Use for journals that require/accept a cover letter at submission. Some journals
have specific rules — check `references/<abbrev>.md` before filling:
- **FAJ**: cover letter MANDATORY, one page, must explain FIT + question + key
  results + practitioner relevance (pasting the abstract is NOT sufficient).
- **JFE / RFS**: cover letter is the ONLY channel to request a data/code-policy
  exemption — write the exemption paragraph if any confidentiality/IP issue.
- **JoE**: state the econometric-methodology contribution + the chosen track
  (Regular / Annals / Themed).
- **JBF / FRL**: a formal cover letter is required for RESUBMISSIONS (with the
  original manuscript number + point-by-point response), optional for new.

Keep it to one page. Plain, specific, no AI-style filler. Author = **Yi-Hao Lai
(賴奕豪)** only. No "volpred" / "AI" / "LLM" / agent branding anywhere.

[Date]

[Editor Name / "The Editors"]

Please consider the enclosed manuscript, **"[TITLE]"**, for publication in
*[Journal Name]* as a [research article / letter / perspective].

**[1 — Question & contribution]** [One or two sentences: the precise question and
the 2-3 concrete contributions. State what is new relative to the closest
published work.]

**[2 — Why this journal]** [One or two sentences tying the paper to the journal's
scope — e.g. policy/institutional relevance (JBF), economic mechanism (JFE/RFS),
econometric methodology (JoE), forecasting + decision value (IJF/JoF),
implementable practitioner payoff after costs (JPM/FAJ), Asia-Pacific setting
(PBFJ).]

**[3 — Headline result]** [One or two sentences: the main empirical/theoretical
result and its magnitude/robustness — sample period incl. a crisis/bear regime,
formal tests used (DM/HLN/MCS, VaR/ES backtesting), and that it survives
robustness checks.]

**[4 — Originality & integrity]** This manuscript is original, has not been
published, and is not under consideration elsewhere. [If a working-paper/SSRN
version exists and the journal permits it, note it here.] All authors have
approved the submission and declare [no competing interests / the interests
disclosed in the declarations].

**[5 — Data & code]** A complete replication package (data + code + README +
data-availability statement) is provided / deposited at [repository], satisfying
the journal's data-and-code policy. [If requesting an exemption for confidential
data, state the reason + the proposed withholding period + that a runnable
synthetic/pseudo dataset is included.]
