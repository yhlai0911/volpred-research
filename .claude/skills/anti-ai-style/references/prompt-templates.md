# 5 大 Prompt 原則 — 寫前下指令範本

來源：NotebookLM 5 sources（特別是「提示詞優化手冊」+ 吳淡如 EP5）。
目的：寫稿前用這 5 條原則組 prompt，能源頭避掉 80% 的 AI 地雷。

---

## 原則 1：年齡 / 角色降級（去除高傲感）

**核心**：AI 預設輸出官腔、書袋氣；強制把作者角色降到「能用普通話講複雜事的人」就會被迫說人話。

### 為什麼有效

LLM 訓練資料中「學術 / 顧問 / TED talk」樣本被 reward 為「專業」，導致預設輸出
就有「高傲感」。把目標受眾從「金融分析師」降到「國二學生」會強迫模型放棄空洞
術語，用通順直白的句子。

### 應用情境

- ✅ 文章面向普通讀者（feed 一般觀眾、FB 貼文）
- ✅ 解釋複雜概念給非專業讀者
- ❌ 學術論文（要保留專業術語，但仍要避地雷 2/3/5/6/7）

### 模板

```
你是一位 [國二學生 / 高中生財經社團主編]，請用 [目標受眾年齡層 - 2] 能聽懂的
詞彙寫這篇文章。禁止使用：
- 「結構性」「本質上是」「深層次」等吊書袋詞
- 任何專業術語必須在第一次出現時用一句白話解釋
- 學術句式（「研究指出…」「文獻表明…」）

讀者目標：[國中三年級 / 完全不懂金融的長輩]

主題：[XXX]
字數：先寫 1000 字，後續會由我裁減
```

## 原則 2：長文裁切法（保護邏輯完整性）

**核心**：AI 控制字數的能力極弱；直接要求 300 字會被砍掉關鍵邏輯。先寫長，再人工裁。

### 為什麼有效

LLM 是 left-to-right autoregressive，被要求短文時會隨機砍邏輯鏈中間段，
結尾常變突兀。先寫 1000 字確保論述完整，再由人類挑「能保留論點密度的好句」
精鍊到 300 字，邏輯不會斷。

### 應用情境

- ✅ 任何 ≤500 字目標的短文（FB hook / push notification / 段落 TL;DR）
- ✅ 推 X / Threads / IG caption
- ❌ Long-form article 本身（直接寫長即可）

### 模板

```
階段 1：請先寫 1000 字長版，論述完整、推理鏈清楚。先不管字數。

[等 AI 寫完 → 人工標記要保留的核心句 / 數字 / 結論]

階段 2：以下是我標記的必保留句子（用 ★ 標出）：
[paste marked text]

請以這些 ★ 句為骨架，精鍊到 300-400 字。不准砍掉任何 ★ 句的論點，但
可以合併、刪掉非 ★ 句、改寫過渡。
```

## 原則 3：強制資訊密度（拒絕迴圈廢話）

**核心**：每一句話必須帶新資訊。沒有 → 合併或刪。

### 為什麼有效

LLM 訓練 reward 偏好長 response；又怕短答顯得不專業，於是學會「換句話說」
注水。在 prompt 直接禁止迴圈，再要求自我檢核，可以斷大半「無效換句話說」
地雷。

### 應用情境

- ✅ 所有產出（這是通用原則）
- 特別需要：摘要、abstract、key takeaways

### 模板

```
寫作硬規則：每一句話都必須提供以下其中之一：
(a) 新的事實 / 數字 / 名稱
(b) 新的因果推論或對比
(c) 新的具體例子

禁止行為：
- ✗ 用 6 句話講 2 句能講完的事
- ✗ 「也就是說 / 換句話說 / 更具體地說」開頭的句子
- ✗ 兩段在講同一個論點但用不同詞彙包裝

寫完後請自我檢核：對每一句問「拿掉這句，文章會缺哪個新資訊？」答不出 → 刪。
```

## 原則 4：負向約束 + 禁用詞清單（預先避雷）

**核心**：直接列禁用句式，讓 AI 不要在這些坑裡跌。

### 為什麼有效

正向引導（「請寫得有人味」）效果差 — AI 不知道什麼叫「有人味」。負向約束
（「不准用 X」）effect 立竿見影 — 模型知道避開。配合 8 地雷 catalog 拿
最高 ROI。

### 應用情境

- ✅ 所有產出（基本配備）
- 特別需要：feed 文章、社群貼文（讀者 AI 偵測 sensitivity 最高）

### 模板

```
禁用句式（違反任一即重寫）：
1. 「不是…而是…」/「不只是…而是…」/「並非…而是…」
2. 「也就是說」「換句話說」「更具體地說」連續 ≥2 個段落
3. 「讓人感到 [情緒]」「不禁 [情緒]」「油然而生」「突然覺得」
4. 「這揭示了」「其實是一場」「背後是」「本質上是關於」
5. 「然而，真正的考驗才正要開始」「悲劇發生了」「命運的轉折」
6. 「有人說」「不少人認為」「坊間流傳」「常聽到」（除非附明確 source）
7. 「這讓人」「這使得」「這意味著」「這代表」段落中出現 ≥3 次
8. 「結構性」「本質上是」「深層次」「多維度」「生態化」「賦能」「閉環」

情緒詞禁直接出現（必用畫面 / 動作 / 意象替代）：
心酸、孤獨、拋棄、震撼、無力、絕望、感動、釋懷
```

## 原則 5：蘇格拉底對槓（防堵事實幻覺）

**核心**：AI 給名言佳句或數據時，立刻反問出處 + 跨模型查證。

### 為什麼有效

LLM 對「fluent-sounding citation」hallucinate 率最高 — 編造名人語錄、
假研究 paper、虛構統計數字看似合理。用「給出處 / 給 DOI / 給原文」反問
+ 跨模型（Gemini Pro / Codex / 我們自己 knowledge.json）cross-check
可以絕大部分戳破。

### 應用情境

- ✅ 任何含 citation / 數字 / 名人語錄的內容
- 特別需要：trending_repost（不引原文但用 primary source 數字）

### 模板

```
規則：當 AI 給出名言、研究、統計數字、歷史事件，你必須在後續對話追問：

「這是誰說的？給出處（書名 + 頁碼 / 演講日期 / DOI / URL）」
「給我這個數字的 primary source link」
「這個歷史事件的具體日期 / 地點 / 涉事人」

得到答覆後跑跨模型驗證（首選 agy 訂閱免費路徑；scripts/gemini_ask.py 會打 PAID API 僅 fallback）：
$ agy -p "驗證：AI 聲稱 X 在 Y 年說過 Z。請查證真實性，附 URL。"

不通過驗證 → 整段刪 / 重寫，禁止保留含「假 citation」的句子。
```

## 5 原則組合模板（複製整段當 prompt header）

```markdown
你是 [國二學生財經社團主編 / 媽媽輩讀者也能懂的部落客]。

【字數策略】
本輪先寫 1000 字長版（後續我會精鍊到 400 字），不限制目前字數。

【資訊密度】
每句必含新資訊（新事實 / 新因果 / 新例子），禁迴圈式「換句話說」。

【禁用句式】（違反即重寫）
- 「不是…而是…」/「不只是…而是…」
- 「也就是說」「換句話說」連續 ≥2 段
- 「讓人感到 / 不禁 / 油然而生」
- 「這揭示了 / 其實是一場 / 背後是」
- 「然而真正的 / 悲劇發生了」
- 「有人說 / 不少人認為」（除非附 URL）
- 「這讓人 / 這使得 / 這意味著」段落中 ≥3 次
- 「結構性 / 本質上是 / 深層次 / 多維度 / 賦能 / 閉環」

【情緒處理】
禁直接寫情緒詞（心酸/孤獨/絕望/震撼）。用畫面、動作、意象烘托。

【事實查核】
所有 citation、數字、名言必附 primary source URL。沒有 → 刪。

主題：[XXXXX]
```

直接貼這段到 Claude / Gemini / 自製 prompt 開頭，再加你的 topic 就行。
