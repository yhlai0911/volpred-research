# 8 大 AI 地雷 — 症狀、根因、修正

來源：NotebookLM `20291e44-e14a-4dbc-9df1-ff4d252f581d` 整合 5 sources。
寫稿時對照自查，editor SOP 階段一強制全 9 句搜尋。

---

## 1. 「不是…而是…」假哲理 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「真正的財富不是口袋的數字，而是對世界的認知。」 |
| **根因** | 為製造偽哲理而把兩個不對等概念強行對立（非對等否定）|
| **AI 動機** | 模型訓練資料中 self-help 文章充斥此句型，認為「哲學感」=「不是 X 而是 Y」 |
| **修正示範** | 「真實財富源於認知深度。」（直接肯定破題）|
| **檢查 grep** | `不是.*而是` / `不只是.*而是` / `並非.*而是` |

進階例外：學術寫作中對比兩個 well-defined 概念可用，但 financial commentary 禁。

---

## 2. 無效換句話說 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「這筆錢沒流動，沒發揮價值，資產正縮水，購買力正下降。」 |
| **根因** | 為湊字數產生缺乏新資訊的迴圈；同一概念用 6 種說法 |
| **AI 動機** | LLM 訓練 reward 偏好長 response；又怕短答顯得不專業 |
| **修正示範** | 「停滯的現金將被通膨蠶食。」（合併四句為一句，每句必含新觀點）|
| **檢查 grep** | `也就是說` / `更具體地說` / `換言之` / `換句話說` 連續出現 |

工具：editor SOP 階段二「逐句新資訊測試」— 每句問「這句帶來什麼新事實/新洞察？」
答不出 → 合併或刪。

---

## 3. 標籤式情緒 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「看著母親老去的背影，讓人感到心酸。」 |
| **根因** | 缺乏真實感情輸出，套用 A+B 標籤公式（情境+情緒詞）|
| **AI 動機** | 直接命名情緒比寫畫面便宜；訓練資料的 Hallmark card 樣本誤導 |
| **修正示範** | 「母親伸手扶牆停了三秒，髮根的白比上週更深一寸。」（畫面替情緒）|
| **檢查 grep** | `讓人感到` / `不禁` / `油然而生` / `突然覺得` |

禁直接出現的情緒詞 reference：心酸、孤獨、拋棄、震撼、無力、絕望、感動、釋懷。
（需要表達 → 用具象畫面、動作、感官細節烘托，留白給讀者）

---

## 4. 爆米花式昇華 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「拒絕一根棉花糖，其實是一場關於人性慾望的深刻對話。」 |
| **根因** | 段落結尾為掩蓋內容空洞，把日常瑣事擴張成宇宙級道理 |
| **AI 動機** | LLM 偏好「ending with grand statement」結構（self-help / TED talk 範本）|
| **修正示範** | 平實呈現動作細節，將感悟留給讀者自己連結（不要替讀者下結論）|
| **檢查 grep** | `這揭示了` / `其實是一場` / `背後是` / `本質上是關於` |

判斷準則：若段尾的「大道理」拿掉，段落是否仍站得住？答 yes → 拿掉就對了。

---

## 5. 生硬戲劇轉折 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「存下第一桶金，然而真正的考驗才正要開始。」 |
| **根因** | 為製造廉價戲劇感濫用連接詞 |
| **AI 動機** | LLM 訓練 narrative cohesion reward；過度泛化「敘事節奏」概念 |
| **修正示範** | 直接接下個動作或數字（讓敘事依邏輯自然流動）|
| **檢查 grep** | `然而，真正的` / `但其實` / `事實上` / `悲劇發生了` / `命運的轉折` |

配額：每篇文章「然而」≤2 次、「真正的」≤1 次。超過必審 SOP。

---

## 6. 稻草人「有人說」⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「有人說買房租不划算，但…」（沒人真這樣說、沒查證）|
| **根因** | 缺乏真實數據或文獻支撐，捏造假想敵製造論點空間 |
| **AI 動機** | 訓練樣本中「先反駁 strawman 再立論」是常見作文範式；LLM 沒查證能力 |
| **修正示範** | 引具體數據：「2025 Q3 全台房租回報率中位數 2.1%（內政部 unc.gov.tw/...）」 |
| **檢查 grep** | `有人說` / `不少人認為` / `坊間流傳` / `常聽到` |

硬規則：任何「有人說」/「數據顯示」/「研究指出」**必附明確 source URL 或 citation**。
無 → 刪句。

---

## 7. 翻譯腔「這」⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「望著母親老去的背影，這讓人不禁感到心酸。」 |
| **根因** | 英文模型訓練餘毒；「This makes one feel...」直譯成「這讓人不禁感到」 |
| **AI 動機** | 中譯英反向訓練樣本污染；中文本身不需要這麼多代名詞 |
| **修正示範** | 拿掉「這」，用具體主詞或直接連續句：「望著母親老去的背影，心揪了一下。」 |
| **檢查 grep** | `這讓人` / `這使得` / `這意味著` / `這代表` |

密度規則：每 200 字「這」字 ≤3 個。超過必清。

---

## 8. 吊書袋空詞 ⛔

| 維度 | 內容 |
|---|---|
| **症狀** | 「這事件揭示了一種結構性的梳理。」 |
| **根因** | 用看似高大上的詞掩蓋內容貧乏（「智慧欺詐」）|
| **AI 動機** | 訓練資料中 academic / consulting 文體被 reward 為「專業」|
| **修正示範** | 追問「結構性的梳理」具體指什麼？答不出 → 刪句或寫具體機制 |
| **檢查 grep** | `結構性` / `本質上是` / `深層次` / `多維度` / `生態化` / `賦能` / `閉環` |

測試：把空詞替換成「東西」/「事情」，句子若仍通順 → 原詞純粹是裝飾，刪。
（「結構性的梳理」→「東西的梳理」仍通 → 確認是空詞）
