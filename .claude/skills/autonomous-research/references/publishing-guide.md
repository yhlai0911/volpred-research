# Publishing Compatibility Pointer

`autonomous-research` 不擁有發布流程。本檔保留舊 deep link 的相容性。

研究端只交付：

- 通過 review 的 experiment id
- canonical result/spec identity
- main-thread knowledge item id
- 可引用的圖表與限制

文章規格、dedup、狀態、發布、通知與 read-back 全部交給
`.claude/skills/feed-publisher/SKILL.md`。研究 agent 不直接修改 feed 或 remote system。
