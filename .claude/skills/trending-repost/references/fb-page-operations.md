# Facebook Page 歷史背景（非 active runbook）

這份文件只保留過去評估粉專 surface 的背景：個人帳號曾有較高自然觸及；粉專 API 權限需要額外 Meta 審核與商業驗證。這些紀錄可用於未來產品決策，但**不得作為現行發文指令**。

現行規則：

- Ivan Lai 個人 FB delivery 的唯一 owner 是 `fb-publishing`。
- 唯一瀏覽器機制是 `scripts/fb_realchrome_post.py`。
- 不因舊粉專 backlog 建立巡檢時鐘、第二個 browser workflow 或同步貼文管線。
- 要恢復粉專營運，必須另開有明確 scope、權限與 acceptance criteria 的正式 task，並先取得用戶對 Page／個人帳號優先序的決策。
