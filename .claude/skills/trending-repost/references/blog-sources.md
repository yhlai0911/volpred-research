- URL: https://havingchien.substack.com/

- Genre 模板：commentary / column tone + 強觀點 + primary-source 重建

## High-Viral Keywords（per 用戶 2026-05-26 強化）

主題優先序（share rate / VolPred monetization 漏斗入口導向）：

1. **AI 發展** — model release、capability jump、enterprise adoption（最 viral）
2. **token maxxing / tokenmaxx / inference economics** — Anthropic / OpenAI / Google pricing wars、cost-per-task crossover、agent economics
3. **矽谷裁員 / tech layoffs / labor displacement** — Meta / MSFT / GOOGL / AMZN 大規模裁員 + AI 替代 narrative
4. AI capex、半導體供應鏈、Mag 7 估值
5. VIX / 波動率 / 對沖、Fed / FOMC / 通膨、地緣政治

**Rule**：source scan 若同時找到 1+2+3 類與 4-5 類，**優先選 1+2+3 類**（高 viral）。VolPred angle 仍需建立（vol regime / labor-displacement vol / token-cost crossover），不可只寫 generic commentary。
