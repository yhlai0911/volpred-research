## 0. 系列切入角度（老闆轉來的背景框架，僅背景，不作引用來源）

美軍防空成本不對稱（用昂貴攔截彈打廉價無人機）→ 俄烏戰爭催化低成本無人機軍備 → 民主陣營推「非紅供應鏈」，有機會複製半導體劇本，把無人機產業鏈往台灣移轉 → 台灣軍工能否靠海外訂單成為「下一座護國神山」。**本系列的探問主軸：台灣接得穩嗎？**（產能、驗證、關鍵零組件自主度、訂單能見度、預算落地風險）

## 1. 台灣無人機產業鏈地圖（三層）

### 上游｜關鍵晶片、飛控、感測、通訊元件
- **飛控晶片 / SoC / MCU**：飛行控制、姿態穩定、電機驅動、邊緣 AI 運算（去紅化核心，「會飛」與「會判斷」的底層神經）
- **通訊 / 射頻元件**：抗干擾資料鏈、微波功率放大、天線、濾波器、圖傳
- **感測 / 光學酬載**：影像感測、光學鏡頭、雲台、AI 物件偵測與避障、光纖陀螺儀（慣性導航）
- **導航**：GNSS / INS、光纖陀螺儀

### 中游｜機體、動力、材料、酬載模組
- **機體結構 / 複合材料**：碳纖維、複材機體、機身與機翼結構件
- **動力系統**：無刷馬達、電動動力總成
- **電池 / 能源**：鋰電池模組、備援電池、能源系統
- **雲台 / 酬載整合**：影像模組、任務酬載

### 下游｜系統整合、系統商、國防採購、服務營運
- **整機製造 / 系統整合**：軍用商規/攻擊型/偵蒐型/FPV 自殺無人機整機、VTOL、系統解決方案
- **地面控制站**：強固型電腦、強固型平板、地面控制器與指管系統
- **海／陸無人載具（正式納入，非延伸）**：無人水面艇（USV）、無人潛航器（造船廠切入）。老闆 2026-07-09 定調「無人艇這種同類型的也可以包含進來」→ 系列 scope = 廣義**無人載具**（空中＋海域＋同類自主載具），與《無人載具採購特別條例》口徑一致（該條例含小型自殺無人艇 1,320 艘）。
- **國防採購通路 / 服務營運**：軍方標案、驗證、維修（MRO）、海外訂單

## 4. PEST 分析骨架（政治 / 經濟 / 社會 / 科技）

### P｜政治 / 政策（皆標日期，立法金額有多版本並存，勿當定論）
1. **無人載具採購特別條例（行政院版）**：2026-06-18 行政院通過，擬 2026-08-01 至 2031-12-31、5 年匡列約 **2,100 億元**，分階段採購約 21 萬架無人載具（沿海監偵約 1,446 架、攻擊型約 20.8 萬架、小型自殺無人艇約 1,320 艘）；強調「國內產製為主、排除中國零件、建非紅供應鏈」。（來源：中央社/自由/經濟日報 2026-06-18）
2. **立法卡關風險**：該條例付委後遭在野（藍白）以人數優勢擋下、決議暫緩；藍營研擬自提版本（6 年 2,400 億元、回歸年度預算）。→ **預算落地時程與金額仍高度不確定**，是投資最大政策變數。（來源：聯合新聞網/CTWANT 2026-06）
3. **不對稱戰力特別條例（對美軍購版）**：另一條 2026-05-08 三讀的「保衛國家安全及強化不對稱戰力計畫採購特別條例」上限約 7,800 億元，核心改為「排除國內自製、僅限對美軍購」，使原國產無人機標案（如市場傳的 500 億標案）面臨排擠/中斷風險。（來源：股感 StockFeel）→ **國產 vs 對美軍購兩條路線並存且相互擠壓**，需在系列中釐清受惠對象不同。
4. **產業政策**：經濟部 2022-08 成立無人機國家隊、嘉義設「亞洲無人機 AI 創新應用研發中心」；行政院 2025-10 通過無人載具產業發展協力計畫，2025-2030 投入約 442 億元打造「民主供應鏈亞太中心」。（來源：行政院/北美智權報）
5. **地緣政治催化**：俄烏戰爭確立低成本無人機戰場價值；美台推「非紅（China-free）UAV 供應鏈」合作（DSET 等智庫倡議）→ 政策順風但受兩岸與美台關係擺盪。

### E｜經濟 / 產業規模
1. **產值成長曲線**：台灣無人機產值 2024→2025 約達 129 億元（媒體引用）；經濟部目標 2028 年產值突破 300 億元、2030 上看 400 億元。
2. **產能目標與落差**：目標 2028 月產能 15,000 架 / 年產約 18 萬架；但 2024-2025 實際年產僅約 8,000-10,000 架 → **產能爬坡是最大瓶頸**（21 萬架採購 vs 現有產能的鴻溝）。
3. **訂單能見度**：軍方大單具「長約、迭代更新」特性，一旦落地帶來多年營收能見度；但目前多為題材/意向，實際簽約與交機節奏未明。
4. **成本不對稱經濟學**：無人機單價低、可消耗，對防守方是成本優勢；對供應商則是「量大、單價低、毛利看規模與關鍵件自主度」的生意模型。
5. **海外訂單想像**：若打入美軍/盟友非紅供應鏈（如雷虎 Blue UAS、參與美軍標案），營收天花板從「台灣國防預算」升級到「全球民主陣營採購」。

### S｜社會 / 需求
1. **全民國防與不對稱防衛共識**：俄烏戰後社會對「刺蝟島/不對稱戰力」接受度提高，支撐長期國防預算。
2. **民用/商用需求**：農噴、測繪、巡檢、物流、災防等民用場景擴張，撐起非軍用產值基本盤。
3. **人才與供應鏈聚落**：嘉義無人機聚落、產學研發中心逐步成形，但軍規驗證人才與量產工程人力仍稀缺。
4. **空域與法規管理**：禁限航區、飛安管理（如空拍法規）影響民用商業化速度。

### T｜科技 / 技術
1. **去紅化（China-free）技術門檻**：飛控 MCU、通訊晶片、電池、關鍵材料需擺脫中國供應，台廠在 MCU（新唐）、RF（立積/全訊）、SoC（聯發科）有既有基礎可切入。
2. **AI 化升級**：從「會飛」到「會判斷」——邊緣 AI 避障、物件偵測、群飛（swarm）、抗干擾自主導航（義隆、中光電切入）。
3. **關鍵自主度落差**：飛控軟體、光學酬載、光纖陀螺儀（亞航）、高能量密度電池是技術護城河，也是目前部分仍需外購的環節。
4. **軍規驗證能力**：Blue UAS 等認證是打入美軍供應鏈的門票，雷虎領先取得；驗證能力=真受惠 vs 純題材的分水嶺。
5. **半導體外溢優勢**：台灣半導體/電子代工能力是無人機「電子腦」與「感測」的天然延伸，也是「複製半導體劇本」論述的技術基礎。

## 5. SWOT 骨架

### S｜優勢（Strengths）
1. 半導體與電子供應鏈完整，飛控晶片/RF/感測/影像有現成台廠基礎（去紅化天然候選）。
2. 政策強力扶植：國家隊、特別條例（雖卡關）、442 億產業計畫、非紅供應鏈定位。
3. 已有取得國際軍規認證的先行者（雷虎 Blue UAS、參與美軍標案），示範打入民主陣營供應鏈可行性。
4. 造船（台船/龍德/中信）延伸無人艇、航太（漢翔/亞航/長榮航太）延伸整機，跨域產能可轉用。

### W｜劣勢（Weaknesses）
1. 產能嚴重落後採購目標（現年產約 1 萬架 vs 目標 21 萬架），量產爬坡是硬瓶頸。
2. 關鍵零組件（高能量密度電池、飛控軟體、部分光學/感測）自主度仍不足，去紅化非一蹴可及。
3. 產業規模小、單價低、毛利敏感，多數概念股無人機營收佔比仍低（題材 > 實質）。
4. 缺乏大規模實戰驗證與長期軍方交機實績，訂單多屬意向/題材階段。

### O｜機會（Opportunities）
1. 全球「非紅無人機供應鏈」重組——美台合作（DSET 倡議）有望把台灣推上民主陣營採購中心，天花板從國內升級到全球。
2. 俄烏戰後低成本無人機成為軍備剛需，長期需求結構性向上。
3. 民用商業場景（農噴/測繪/巡檢/物流/災防）擴張，撐非軍用基本盤。
4. 「下一座護國神山」敘事若成形，帶動資本市場評價重估與資金投入。

### T｜威脅（Threats）
1. **預算政策風險（最大威脅）**：特別條例卡關、國產 vs 對美軍購路線互斥，預算落地時程/金額高度不確定，直接衝擊國產受惠鏈。
2. 中國無人機（DJI 等）成本與規模碾壓，全球民用市場競爭激烈；紅色供應鏈價格戰。
3. 兩岸/美台關係擺盪、美國政策不確定性影響海外訂單與技術合作。
4. 題材過熱→本夢比評價風險（2026-07 多檔漲停），基本面未跟上時的回檔風險。
5. 產能若無法如期爬坡，採購案可能轉向進口或延宕，國產鏈受惠不如預期。
