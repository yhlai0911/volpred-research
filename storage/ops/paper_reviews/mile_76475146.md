## 2. Lookahead and timing audit

PASS for the claims actually used by this article.

- K820 event-day de-risking uses same-day event calendar flags for FOMC/NFP/CPI. This is acceptable for a calendar-event strategy because the dates are public before the event day; the article does not frame the event date as a learned market signal. See `experiments/k820/k820_event_risk_budgeter.py:344-373`.
- K820 market-data conditions are lagged: `VIX.shift(1)` is used for the VIX-conditioned event strategy and the `12/VIX` benchmark. See `experiments/k820/k820_event_risk_budgeter.py:350-378`.
- K741 VIX-regime conditioning uses previous-day VIX via `VIX_prev = VIX.shift(1)` before classifying NFP regimes. See `experiments/k741/k741_nfp_event_study.py:81-85` and `experiments/k741/k741_nfp_event_study.py:204-211`.

Non-blocking caveat: K741's separate NFP reduction strategy uses `NFP_signal.shift(1)` in a way that appears to reduce exposure after the NFP day, not on it. The digest does not cite K741's strategy-performance numbers, so this does not invalidate `mile_76475146`, but K741 should not be used for tradable NFP avoidance claims without a fresh review of that branch.

These do not require retracting or editing the article, but they matter before reusing the same artifacts in paper-grade claims:

1. `experiments/k820/README.md` and `experiments/k741/README.md` are still placeholder planning files, so the review relies on results JSON plus source code rather than full experiment READMEs.
2. K820's script writes to an absolute output path outside the cited folder (`experiments/k820_event_risk_budgeter_results.json`) instead of `experiments/k820/k820_event_risk_budgeter_results.json`. The committed results file currently matches the article, but rerunning the script may not refresh the cited artifact unless this path is fixed.
3. K820 labels CPI dates as approximate in code. The digest's CPI usage is broad and descriptive, not a precise CPI-event inference, so the article remains acceptable.
