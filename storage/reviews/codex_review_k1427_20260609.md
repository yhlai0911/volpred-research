## 結論摘要

K1427 的核心裁決基本成立：主路徑沒有 lookahead，`seed=42` 固定，`external_claim_verdict`
也沒有硬拗，對 2026-06-05 這次 selloff 給 `MIXED` 是誠實的，因為防禦板塊確實逆勢、
但 `XLE` 當天是負報酬。不過這份 PoC 仍有 3 個方法論 caveat，需要在後續文章或
knowledge 記錄裡明講，不宜包裝成 fully clean statistical result。

## Findings

1. **Q1 的顯著性檢定把時序資料當成獨立樣本** — [k1427.py](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/k1427.py:93), [README.md](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/README.md:7)
   - `Welch` 與 `Mann-Whitney` 直接比較 `101` 個大跌日與 `3024` 個平常日，但大跌日實際只形成 `69` 個 clustered episodes，且 dispersion 本身有 serial dependence。
   - 影響：`p=3.2e-12` 的精準度偏樂觀；效果方向大致可信，但「極度顯著」這種話術太強。
   - 建議：後續改用 episode-level bootstrap / permutation，或至少在 prose 改成「差異很大、傳統 t-test 顯著，但未校正時序相依」。

2. **Q5 的 future-RV 窗口定義與 README 說明不一致** — [k1427.py](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/k1427.py:200), [README.md](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/README.md:43)
   - `shift(-1).rolling(N).std().shift(-(N-1))` 不是 README 寫的乾淨 `t+1..t+N` 對齊；它仍然看向未來、不是 lookahead，但 forward window 實際落點滑後。
   - 影響：Q5 的數字不能精確解讀為「大跌後未來 N 日波動」。
   - 建議：把 Q5 降格成 exploratory note，或重寫 forward-RV 對齊後再引用數字。

3. **JSON `definitions` 還保留舊的一維 regime 定義，和實際 2-D taxonomy 不一致** — [k1427.py](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/k1427.py:353), [k1427.py](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/k1427.py:376)
   - `definitions.rotation_regime` / `liquidation_regime` 只寫 dispersion 門檻，但真正分類邏輯已經是 `dispersion × 方向廣度`，中間還有 `broad_selloff_high_disp`。
   - 影響：下游若只讀 `definitions`，會誤以為 K1427 只是單門檻分類。
   - 建議：同步修正 `definitions`，讓 JSON metadata 與實作一致。

4. **Task brief 要求的 `0050 dispersion robustness` 並未實作** — [README.md](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/README.md:24), [k1427.py](/Users/yhlai0911/Desktop/volpred-research/experiments/k1427/k1427.py:56)
   - K1427 全部資料都在美股 `SPY + SPDR sectors`；沒有 `0050.TW`、沒有台股 sector proxy，也沒有 cross-market robustness。
   - 影響：不能把這篇結論寫成「股市大跌普遍如此」或延伸到台股。
   - 建議：若要補齊 task brief，另開 follow-up 做台股/0050 的產業分散度 proxy；在目前文章中明寫「僅限美股 sector ETF」。
