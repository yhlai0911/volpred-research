# 修掉 lookahead bug 後，台股開盤訊號反而更強？K521 給了一個很罕見的答案

多數時候，研究裡一旦抓到 lookahead bug，接下來的劇情通常很熟：

原本漂亮的結果會縮水，甚至直接消失。

`K521` 很不一樣。它抓到的不是小 bug，而是會動到訊號定義本身的時間對齊錯誤；但修掉之後，結果不是變弱，反而變得更強。

這也是為什麼這篇實驗值得寫成文章。因為它同時示範了兩件事：

1. **lookahead 問題真的會扭曲結論**
2. **但扭曲的方向，不一定是把績效誇大，也可能剛好把真正的訊號洗掉**

## bug 在哪裡

核心問題很簡單：台股和美股不在同一個時區。

台股早上 `9:00` 開盤時，美股前一晚的收盤價其實才剛在台灣時間清晨 `5:00` 出來。這中間只有大約四個小時，但在資訊順序上差很多。

`K521` 發現，舊版本 `K519/K520` 在資料合併時用了 `merge_asof(direction="backward")`。這會讓台股日期 `T` 對到同一個日曆日的 `SPY(T)`，而不是理論上該用的 `SPY(T-1)`。

問題是，`SPY(T)` 的收盤在台灣時間上其實發生在**台股 `T` 已經交易完之後**。這就是標準的時間對齊錯誤。

診斷結果很直接：

- same-day 錯配有 `3783` 天
- 佔樣本的 `96.7%`
- `1-day` 訊號有 bias
- `2-day` 訊號沒有同樣問題

## 最反常識的地方：修正後的 1-day 訊號不是變差，而是暴衝

這是 `K521` 最值得注意的地方。

![K521 bugfix comparison](experiments/k521/k521_general_bugfix_comparison.png)

先看幾個關鍵版本：

- `No SPY signal`：Sharpe `0.551`
- `1d buggy`：Sharpe `1.076`
- `1d correct`：Sharpe `4.445`
- `2d buggy`：Sharpe `3.550`
- `2d correct`：Sharpe `3.319`

原本的直覺可能會說：

> 既然舊版用了不該看到的資訊，修掉之後績效應該會掉下來。

但這裡沒有。

真正的 `1-day correct` 不只沒掉，還比 buggy 版本高出一大截，從 `1.076` 直接跳到 `4.445`。年化報酬也從 `4.36%` 拉到 `16.87%`，最大回撤反而更淺。

這代表什麼？

代表舊 bug 不是把策略吹得太漂亮，而是把真正有效的 `SPY(T-1)` 訊號，和沒有預測力甚至反方向的 `SPY(T)` 混在一起，結果把 alpha 稀釋掉了。

換句話說，**buggy 版本比較像把真訊號摻水，不是偷吃步。**

## 第二張圖更重要：真正的資訊窗口只有一天

如果這條訊號是真的，那它應該會隨著 lookback 拉長而衰減。

`K521` 的結果確實是這樣：

![K521 decay curve](experiments/k521/k521_general_decay_curve.png)

corrected `n-day` 訊號的 Sharpe 呈現單調下降：

- `1d = 4.445`
- `2d = 3.319`
- `3d = 2.816`
- `5d = 2.297`
- `10d = 1.574`
- `21d = 1.025`

這條曲線很有說服力，因為它不像隨便挖到的 data-mining 噪音。它更像是一個很清楚的時區傳導機制：

**昨天美股收盤的資訊，對今天台股開盤缺口最有用；時間一拉長，訊號就快速衰減。**

這和 `K521` 自己給出的診斷一致：

- `corr(SPY_T-1, TW_gap) = 0.611`
- `16/16` 年都為正
- 最低年度 Sharpe 也還有 `3.486`

## 但別太快把它當成可直接下單的 holy grail

這篇實驗很強的地方，是它沒有因為數字太漂亮就自動宣告可交易。

因為這個 alpha 幾乎全部來自**台股開盤缺口**。

實驗裡也明講了：

- gap-only Sharpe = `5.644`
- intraday Sharpe = `0.453`

這代表策略的核心不是「白天盤中慢慢發酵」，而是開盤那一瞬間就已經反映大部分資訊。

於是實務問題立刻冒出來：

- 現貨 `0050.TW` 幾乎不可能在台股收盤後、又在隔天開盤前，靠這個訊號舒適進出
- 台指期夜盤理論上比較有機會，因為美股在台灣時間清晨 `5:00` 收盤，台灣期貨夜盤差不多也在那附近結束

但這種操作窗口極窄。你可能在研究上抓到一條很乾淨的資訊傳導通道，卻未必能在真實交易裡完整把它吃下來。

所以 `K521` 最誠實的定位不是「找到一套可直接量產的策略」，而是：

**它確認了一條很強的台美時區傳導事實，但這條事實和可落地交易之間，還隔著執行摩擦。**

## 這篇實驗為什麼重要

因為它提供了一個很少見、但方法論上很寶貴的案例：

不是每個 lookahead bug 都會把結果往上吹。有些 bug 會把真正存在的訊號搞亂，讓你低估它。

這也提醒研究者：

如果你看到一個修正後的結果變得更強，不要第一時間以為那一定有鬼。先去問：

> 原本的 bug，到底是偷看未來，還是把兩種不同時間點的資訊錯混在一起？

`K521` 屬於後者。

## K521 的一句話結論

修掉時區對齊 bug 之後，台股開盤前真正該用的是前一晚美股收盤 `SPY(T-1)`，而不是同日 `SPY(T)`；這樣做會讓 1-day 訊號更強，並揭露一條非常短、非常集中的台美資訊傳導窗口，但這條窗口未必容易直接交易。
