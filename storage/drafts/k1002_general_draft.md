# 同一場模型擂台賽，最後只剩兩個人站著

很多人在看市場模型時，會自然以為一件事：

你把公式做得更複雜、把變數加得更多，表現應該就會更好。

這次我們把七種常見做法放進同一套規則裡比賽，結果剛好在提醒一件相反的事：

**不是越複雜越厲害，而是誰比較早看懂市場現在是不是在緊張。**

這場比較用的是同一段 SPY 樣本外資料，從 2019 年到 2026 年，總共 1,825 個交易日。所有方法都用同一段考卷、同一套打分方式，沒有誰可以靠換樣本或換期間佔便宜。

## 七個選手一起上場，最後只剩兩個人

這次上場的七個方法，大致可以分成四類：

- 老派做法：只看價格自己怎麼震盪。
- 帶市場恐慌訊號的做法：把 VIX 這種「現在大家有多怕」的訊號一起放進來。
- 想靠總經資料加分的做法：把利差、失業等變數一起塞進來。
- 想靠簡化規則取勝的做法：用比較粗略的歷史波動規則去猜明天。

比完之後，真正留下來的只有兩個，而且是同一家族。

| 方法 | 預測分數 |
|------|----------|
| **A4f-N** | **-8.361** |
| **A4f-t** | **-8.361** |
| Macro-X | -8.270 |
| GJR-t | -8.266 |
| GJR-N | -8.263 |
| 另一種波動率變形版 | -8.247 |
| HAR-ABS | -8.200 |

這張表最值得記住的地方，不是第三位小數，而是斷層。

前兩名不是剛好小贏，而是直接把其他五個方法甩開。換句話說，當你把所有人都放到同一場公平比賽裡，最後能留下來的不是「變數最多的人」，也不是「名字最複雜的人」，而是那兩個有先把市場恐慌訊號讀進去的方法。

## 真正分出高下的，不只是哪個猜得準

只看預測分數還不夠。做風險管理的人真正關心的是：

**市場真的大跌時，你畫的安全線有沒有守住。**

這次的第二張成績表，就是在看七個方法面對大波動時，誰比較不容易失手。

| 方法 | 風險守線成績 |
|------|--------------|
| **A4f-t** | **7 / 7** |
| A4f-N | 5 / 7 |
| GJR-N | 3 / 7 |
| Macro-X | 2 / 7 |
| GJR-t | 1 / 7 |
| 另一種波動率變形版 | 1 / 7 |
| HAR-ABS | 1 / 7 |

這裡又出現同一個畫面。

第一名還是 A4f 家族，而且帶厚尾設定的版本直接拿到滿分 7/7。第二名也是 A4f 家族。剩下其他五個方法，成績全部掉到中後段，甚至有三個方法只拿到 1 分。

這代表什麼？

代表前面那個「預測分數比較好」不是紙上談兵。它真的有轉成比較實際的保護力。平常猜得比較準，碰到大波動時也比較不容易把風險看得太輕。

![圖 2：風險守線成績，滿分的只有 A4f-t，一大票其他方法掉到後段班](https://qxhfgdfzazwpkdgesavm.supabase.co/storage/v1/object/public/article-images/k1002_scorecard_27c911.png)

## 這份結果最反直覺的地方

很多人原本會以為，加入總經資料應該比較強。

畢竟景氣、利率、失業聽起來都很重要，直覺上好像比單純看市場價格更「全面」。但這次統一比較給的答案不是這樣。那個塞進總經資料的版本，最後排在第三到第六名這個區間，既沒有逼近領先組，也沒有在風險守線上特別突出。

另一個容易讓人誤會的是：有些模型名字很複雜，看起來很像高級升級版，但真的丟進同一場實戰考試後，表現未必比老派做法更好。

這其實很像買工具。

不是功能表列得越長越有用，而是你要先問：它有沒有真的抓到最重要的訊號？

在這份比較裡，最重要的訊號不是「變數越多越厲害」，而是**有沒有先把市場恐慌本身讀進去**。

## 兩個冠軍之間，差別又在哪裡

前兩名其實非常接近，預測分數幾乎一樣。

真正拉開最後差距的，是後面那一點點尾部保護。

白話講就是：

- A4f-N 已經很強，平常表現夠好。
- A4f-t 則是在市場最兇、最容易失手的那幾段，再補上一層保護，所以整體守線成績更完整。

這也讓整件事看起來更合理。

不是說厚尾設定本身能把爛模型變神，而是當你的底子已經對了，它才有機會幫你把最後那幾個脆弱角落補起來。

## 一般投資人可以帶走什麼

第一，不要把「模型很複雜」直接翻成「模型比較可靠」。

第二，市場的情緒溫度有時候比你想像的重要。當大家突然變得很怕，很多只看歷史價格的做法反應就是會慢一拍。

第三，如果一套方法在平均分數和風險守線都排前面，它比起那種只在單一指標好看的方法，更值得你多看兩眼。

## 一句話收尾

這場七人擂台賽最後很乾脆：**真正留下來的，不是最花俏的模型，而是最早讀懂市場恐慌的那一類。**
