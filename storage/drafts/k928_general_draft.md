# BTC 鏈上指標能預測比特幣波動嗎？看似可以，實際上不行

> 加密貨幣有一個讓研究者眼睛發亮的特點：**所有交易都記在鏈上**。比起傳統股市要靠交易所揭露、監管申報，BTC 的鏈上資料像一座開放的金山——理論上你可以看到每一筆轉帳、每一個錢包的動向。那這座金山能不能用來**預測比特幣的波動率**呢？我們把 7 個常用指標放上 9 年資料，認真測一遍。答案是：**樣本內看似有訊號，樣本外完全洗掉，而且最需要避險的高波動期反而失效**。這篇文章誠實記錄這個 NULL 結果，並說明它對加密貨幣研究意味著什麼。

## 一個聽起來合理的假設

加密市場的一個常見論述是：「鏈上資料領先價格」。這個論述通常包含幾個經典指標：

- **BTC-ETH 相關性**：當兩個主要加密貨幣高度同向時，市場通常處於極端情緒
- **波動率週期結構**：短期實現波動率與長期實現波動率的比值，反映市場是否處於異常狀態
- **BTC 主導率變動**：資金在 BTC 與其他加密貨幣之間的輪動
- **加密 vs 傳統金融背離**：BTC 與 SPY 走勢脫鉤的程度
- **週末波動率**：傳統市場休市、加密市場 24/7 開盤期間的特殊波動

聽起來都很合理。如果這些指標真的有預測力，那麼一個結合它們的模型，應該能比「只用比特幣自己的歷史波動率」這種 baseline 預測得更準。

我們做了這個測試——**結果不是這樣**。

## 樣本內：4 個指標達顯著，看起來有戲

我們用 2017-01-01 到 2026-03-21 共 2074 個觀察日的資料，先用 BTC 自身 22 日歷史波動率作為 baseline 解釋當下的實現波動率（R² = 20.1%），再逐一加入 7 個鏈上指標檢視「是否有額外解釋力」。

| 鏈上指標 | 樣本內統計強度 | 是否達顯著 |
|---|---|---|
| BTC-ETH 相關性（22 日） | 4.16 | 是 |
| 波動率週期結構（5d/22d） | 3.61 | 是 |
| 週末 BTC 波動率 | 2.34 | 是 |
| BTC-SPY 相關性 | 2.27 | 是 |
| BTC 主導率變動 | 1.85 | 否（邊界） |
| 加密-傳統背離 | 0.97 | 否 |
| BTC/ETH 比率變動 | 0.96 | 否 |

**7 個指標中 4 個達顯著**——樣本內看起來像是發現了「真東西」。把這 4 個指標一起塞進模型（kitchen sink 做法），對 baseline 的**增量解釋力 ΔR² = +4.42%**，看起來相當可觀。

如果故事到這裡就結束，這會是一篇「BTC 鏈上指標確實有預測力」的捷報。**但研究誠實原則要求樣本外驗證。**

## 樣本外：訊號完全消失

把資料切成訓練集與保留集，用訓練集估計係數、保留集做預測，再用嚴謹的兩模型比較檢定逐筆比較預測誤差，結果是：

| 比較項 | 數值 |
|---|---|
| 樣本外觀察數 | 125 天 |
| Baseline 樣本外 MSE | 0.04156 |
| 完整模型樣本外 MSE | 0.04127 |
| 樣本外 ΔR² | +0.7%（相對於 IS 的 +4.42%） |
| **兩模型比較統計強度** | **0.17（完全達不到顯著）** |
| 對應的 p 值 | 0.43 |

樣本內 ΔR² +4.42% → 樣本外 +0.7% → 統計強度 0.17 ≈ 雜訊。

這是**經典過度配適（overfitting）的訊號**——你以為自己抓到了規律，其實只是抓到了那段歷史的特定噪音。當你把這個「規律」搬到新資料上，它不再成立。

![樣本內 4 個指標看似強訊號，樣本外的兩模型比較統計強度卻只有 0.17——訊號完全洗掉](https://qxhfgdfzazwpkdgesavm.supabase.co/storage/v1/object/public/article-images/k928_is_oos_gap_46acfd.png)

## 教給讀者的第一件事：樣本內 R² 不是 alpha 證據

這個結果其實重複了金融計量學界一個老教訓：**樣本內顯著 ≠ 樣本外可用**。

很多加密貨幣的「研究」（特別是社群媒體上流傳的那種）只展示樣本內回測——「我發現某個鏈上指標和未來價格相關，統計強度 4.5！」這種陳述常常是真的，但它**不等於** 你拿著這個指標進場真的會賺錢。原因有兩個：

1. **資料探勘**：在 7 個指標裡找出 4 個顯著，背後可能是「我試了 50 個指標，剛好這 4 個過了」的選擇偏誤
2. **結構性變遷**：加密市場 2017-2021 的特性與 2022-2026 已經明顯不同，樣本內找到的關係可能在樣本外已不成立

**檢驗方法很簡單**：任何聲稱有預測力的指標，先問「樣本外驗證做了嗎？嚴謹的兩模型比較檢定通過了嗎？」如果答案是否定的，把那個強度 4 的數字當作茶餘飯後的觀察就好，不要拿它做交易決策。

## 但故事還沒完：更糟的事情是——危機時失效

樣本外 NULL 已經是壞消息，但接下來的發現更值得警惕。

我們把資料按 VIX（市場恐慌指數）切成「平靜期」與「危機期」兩段，分別重新檢視這些鏈上指標的解釋力：

| 市場狀態 | 觀察數 | BTC-ETH 相關性指標的統計強度 | ΔR² |
|---|---|---|---|
| **低 VIX（平靜期）** | 1721 天 | **6.80（極強）** | +1.92% |
| **高 VIX（危機期）** | 353 天 | **1.72（不顯著）** | +0.77% |

**訊號在低 VIX 時期非常強，在高 VIX 時期幾乎消失。**

![關鍵限制：低 VIX 時期統計強度高達 6.80，高 VIX 時期卻只剩 1.72 完全達不到顯著](https://qxhfgdfzazwpkdgesavm.supabase.co/storage/v1/object/public/article-images/k928_regime_asymmetry_69717a.png)

這個現象有個專業名稱叫 **regime asymmetry（狀態不對稱）**，它在風險管理上是**致命缺陷**。

道理很直觀：

- **平靜期你不需要避險**。市場本來就乖，預測對與錯影響都不大。
- **危機期你才真正需要好的波動率預測**——要做避險、要調整部位、要管控風險。

但這些鏈上指標**正好相反**——平靜時還能用，一進入危機就失效。這等於在告訴你：「這個工具在你不需要它的時候很好，在你最需要它的時候沒用。」

從風險管理的角度，**這比 NULL 更糟**——NULL 至少誠實地告訴你「沒有」，狀態不對稱會讓人誤以為「平常都很準，這次只是意外」，從而在危機中放錯信任。

## 週末效應：達顯著但相關性太弱

實驗中還有一個附帶發現。加密市場 24/7 不打烊，但傳統金融在週末休市。我們檢查「週末 BTC 波動率」是否能預測「週一 SPY 波動率」：

| 統計量 | 數值 |
|---|---|
| 觀察數 | 432 個週末-週一配對 |
| 相關係數 r | **0.164** |
| 對應的 p 值 | 0.0006（達顯著） |
| 高 vs 低週末波動的週一 \|報酬\| 對比 | 0.92% vs 0.56%（兩組比較統計強度 2.28，達顯著） |

統計上**達顯著**——確實有訊號。但 r = 0.164 意味著什麼？

意味著週末 BTC 的波動率，**只能解釋週一 SPY 波動率變異的 2.7%**（r² = 0.027）。剩下 97.3% 是其他因素。

![週末效應：r = 0.164 達顯著，但作為交易訊號相關性太弱，遠不及 VIX 等核心指標](https://qxhfgdfzazwpkdgesavm.supabase.co/storage/v1/object/public/article-images/k928_weekend_effect_14234f.png)

統計顯著 ≠ 經濟顯著——這是金融計量另一個重要區分。樣本夠大時，連微弱的關係也會「達顯著」，但拿來做交易決策，0.164 的相關性會被交易成本與滑價輕易吞掉。**這個指標可以寫進論文當作觀察，不應該拿來操作部位**。

## 一個更深層的解釋：VIX 已經把該有的資訊吃光了

這篇實驗的第三個值得一提的發現是它**再一次確認了 VIX-sufficiency**。

VIX-sufficiency 是這個研究計畫累積 30+ 次驗證後逐漸浮現的一個結論：**對於日頻波動率預測，VIX 幾乎吸收了所有可預測的系統性不確定性，再加任何其他結構訊息（不管是個股財報、實質波動率分解、還是這次的鏈上指標），邊際資訊量都接近於零**。

這個結論之前在多種情境驗證過：

- 跨資產共同因子（K928 Factor GARCH）：PCA 因子解釋了 59% 的跨資產共同波動，但相對於 VIX 增量為零
- 個股財報事件（K1067）：台積電財報日訊號在 A4f-VIX 框架裡完全失效
- 實質波動率分解（K1057）：日內 vs 隔夜分量在 VIX 之外無增量

而現在 K928 從**加密貨幣領域**——一個和 VIX 標的（S&P 500）完全不同的市場——再次得到同樣結論。鏈上指標看似獨立於傳統金融，但對於 BTC 自己的日頻波動率預測，仍然「VIX-sufficient」（VIX 已足夠吸收這層資訊）。

加密市場的「內部資訊獨立性」可能比社群媒體宣稱的少很多。

## 把這些經驗送給做加密研究的讀者

K928 這個 NULL 結果可以給對加密貨幣研究有興趣的讀者四個提醒：

1. **樣本內 R² 不是 alpha 證據**。任何聲稱「我發現了 XX 指標能預測 BTC」的說法，**先問是否做過嚴謹的樣本外驗證**。沒做，當茶餘飯後觀察看就好。

2. **狀態檢測必做**。把資料切高低波動期分開測，是檢驗一個指標「是不是危機時還能用」的最低標準。如果只在平靜時有效，那它對風險管理沒幫助。

3. **加密市場的「內部資訊」對價格預測幫助有限**。鏈上資料對於**鏈上活動本身**（例如預測下一個 halving、礦工行為）當然有用，但對於**價格與波動率的日頻預測**，目前的證據顯示它沒提供傳統金融指標（如 VIX）以外的增量資訊。

4. **VIX 已 price 多數可預測的系統性風險**。加密市場不是例外，反而是另一個確認案例。如果你只能選一個指標來追蹤系統性風險，VIX 仍然是預測波動率最高 CP 值的工具。

## 寫這篇文章的初衷

這個 NULL 結果不會登上加密媒體頭條——「BTC 鏈上指標 OOS 不顯著」遠比「鏈上指標領先 BTC 價格 30%」沒有點閱率。但研究誠實原則要求 NULL 結果與 PASS 結果一樣完整地報告。

更重要的是，這個 NULL 排除了一條看起來合理但實際不通的研究路徑——它告訴我們**未來如果要用加密貨幣資訊來增強傳統市場波動率預測，不應該再走「鏈上指標當外生變數」這條老路，要找的是更高頻、更結構性的資訊（例如永續合約資金費率的極端值、清算瀑布的時序結構），而不是這 7 個常見的價格衍生指標**。

每個 NULL 都讓研究空間縮小一點。這就是我們持續做這類測試的原因。

## 引用實驗

K928 — Crypto on-chain proxy → BTC vol MARGINAL（2026-03-21 完成）。本實驗測試 7 個鏈上指標對 BTC 日頻波動率的解釋力與樣本外預測力，發現樣本內 4/7 達顯著（ΔR² = +4.42%），但樣本外兩模型比較統計強度僅 0.17（NULL）。狀態分析揭示低 VIX 期訊號強（統計強度 6.80）、高 VIX 期失效（統計強度 1.72）的不對稱限制——危機時最沒用。VIX-sufficiency 在加密貨幣領域得到第 32+ 次跨情境驗證。本實驗為加密貨幣 vol 預測研究線（K7 vol spillover、K99 DeFi IL、G25 內部 lead-lag、T26 BTC-SPY integration）的 OOS 嚴謹度補強。
