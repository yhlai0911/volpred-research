# 一個策略要怎樣才算真的過關？K551 的答案是：不是賺得多，而是質疑扛得住

先講清楚，`K551` 已經有一篇較早的 general 文章。那篇講的是「這套 VIX 條件槓桿值不值得用」，重點放在策略本身的直觀效果。

這篇不是重寫那個結論，而是補上同一個實驗更核心、也更少被一般文章講清楚的一面：

**一套策略從「看起來有效」走到「接近可上架」，真正靠的不是再秀一次高報酬，而是把交易成本、cross-OOS、borrow cost、bootstrap 這些質疑一條條關掉。**

很多投資研究做到一半就停了。

前面可能很漂亮：

- Sharpe 比基準高
- 回撤比較淺
- 回測圖長得很順

但只要再往前追兩步，問題就開始冒出來：

- 只是剛好吃到某段行情嗎？
- 交易成本一算就沒了嗎？
- 借錢槓桿一加進去就破功嗎？
- 換一個切法、換一個參數，還活得下來嗎？

`K551` 的價值，不是又發現一個新策略，而是把前一輪已經看起來很不錯的 `K548`，拉進一個更像「上市前體檢」的流程，逐條檢查它到底扛不扛得住。

最後的答案很少見，也很乾淨：

**10 個驗證裡過了 9 個，這套 VIX 條件槓桿策略不是只有回測好看，而是真的接近可上架。**

## 先講結果：它不是把基準打成廢物，而是把一個本來就很強的基準再往上推

基準不是什麼弱雞策略，而是已經很強的 `12/VIX` 波動率管理版 `SPY/GLD`。

`K551` 測的是：在這個基準之上，再加一層條件式槓桿調整，值不值得。

![K551 validation summary](experiments/k551/k551_general_validation_summary.png)

全樣本結果是：

- `12/VIX base` Sharpe = `1.367`
- `VIX-conditioned leverage` Sharpe = `1.474`

年化報酬也一起往上：

- base CAGR = `12.68%`
- strategy CAGR = `17.98%`

更重要的是，這不是只在單一總樣本裡成立。

主 cross-OOS 五段裡，它 **5/5 全勝**：

- `2005-2009`
- `2009-2013`
- `2013-2017`
- `2017-2021`
- `2021-2026`

平均 Sharpe 差是 `+0.13`。這不是那種只在某一段牛市突然很會飛的故事，而是不同市場環境下都還能維持領先。

## 這篇真正重要的地方：它把最麻煩的質疑一條條處理掉

`K551` 的重點不是「績效又多高了 0.1」，而是它把最常見的反對意見逐條過了一遍。

最終 verdict 很直白：

- `9/10 checks pass`
- `listable = True`

通過的項目包括：

- 兩種主要統計檢定都過關
- 兩種 cross-OOS 切法都穩
- 參數敏感度 safe zone 足夠大
- `6%` 借款成本下仍贏基準
- bootstrap 信賴區間不含 `0`
- bootstrap 幾乎每次都贏

唯一表面上沒過的，是交易成本那一關。

但也正是在這裡，`K551` 最值得讀。

## 交易成本爭議：算「全部 turnover」和算「增量 turnover」，是完全不同的故事

很多策略一碰到高周轉就會死。這套條件槓桿策略看起來也一樣，因為它的總年換手率很高：

- total strategy turnover = `1459.8%/yr`

如果你把這整筆都算到策略頭上，break-even transaction cost 只剩 `3.8bps`，看起來幾乎不能碰。

但 `K551` 指出，這個算法其實不公平。

因為基準 `12/VIX` 本來就不是靜態配置，它自己也有很高的基礎換手：

- base turnover = `791.9%/yr`

新策略真正額外帶來的，是：

- incremental turnover = `667.9%/yr`

![K551 transaction-cost story](experiments/k551/k551_general_tx_cost_story.png)

一旦你把成本只算在**增量換手**上，故事就變了：

- total-turnover 口徑的 break-even = `3.8bps`
- incremental-turnover 口徑的 break-even = `14bps`

這個差很多。因為 `SPY/GLD` 這類 ETF 的實際 spread 大約就是 `1-2bps` 等級，離 `14bps` 還很遠。

所以 `K551` 的結論不是「交易成本不重要」，而是：

**交易成本要算對基準。**

如果你把基準本來就會產生的周轉也全灌到新策略頭上，你不是在做保守檢驗，而是在算錯問題。

## 為什麼這篇比一般策略文章更有價值

因為多數投資文章都停在「看，我找到一條線比另一條高」。

`K551` 比較像一場審問：

- 你只是在全樣本好看嗎？
- 換切法還行嗎？
- 換參數還活著嗎？
- 加借款成本呢？
- 加 bootstrap 呢？
- 放到台灣市場呢？

這樣一輪跑完，還能站著的策略，才比較接近可用。

有趣的是，這篇也順手劃出了它的邊界。

在台灣那條線上，同樣的條件槓桿邏輯**沒有複製成功**。`K551` 的優勢是美股 `SPY/GLD` 線路上的結果，不是 universality claim。

這反而讓整個結論更可信。因為它不是什麼「哪裡都能賺」的萬能模板，而是條件很清楚的、經過深驗證的局部優勢。

## 對投資人最有用的一句話

如果你平常就喜歡看新策略，`K551` 最該教你的不是哪個參數，而是：

**真正值得重視的策略，不是第一次回測最亮眼的，而是第十次被質疑之後還沒倒的。**

`K551` 的價值就在這裡。它把「看起來有效」往前推了一步，推到「經過一整套壓力測試後，仍然值得考慮上架」。

## K551 的一句話結論

`K551` 不是再發現一個新 alpha，而是把一套已知有優勢的 `SPY/GLD` VIX 條件槓桿策略，從漂亮 backtest 驗證成可上架候選。10 個檢查裡過了 9 個，最敏感的交易成本問題也在改用「增量 turnover」口徑後得到合理解釋。
