# SKEW 指數真的能比 VIX 更早看到風險嗎？K181 的答案是：有訊號，但不夠強

如果 `VIX` 是市場對「整體恐慌」的溫度計，那 `SKEW` 想量的就是另一件事：

> 投資人是不是正在默默替尾部風險買保險？

直覺上，這很吸引人。因為如果尾部保護需求先升高，也許它會比一般波動率指標更早透露風險正在堆積。

`K181` 檢查的，就是這個想法到底有沒有辦法變成真正有用的預測工具。

答案不是單純的 yes 或 no，而是比較誠實的一句話：

**`SKEW` 確實帶有一些額外訊號，但強度不大；一旦進入真正的 forecasting 與策略檢定，它沒有證明自己能穩定打敗既有做法。**

## 先看第一層：SKEW 不是完全沒東西

這個實驗用的是 `2005-01-04` 到 `2025-02-28` 的 `5008` 筆日資料，主要比較 `SKEW`、`VIX` 與未來 `SPY` 波動之間的關係。

如果只看原始相關，`SKEW` 和未來波動確實有關，而且方向很一致：

- `1d` raw correlation: `-0.166`
- `5d` raw correlation: `-0.226`
- `22d` raw correlation: `-0.217`
- `66d` raw correlation: `-0.201`

這代表什麼？

代表 `SKEW` 高的時候，接下來的實現波動率平均反而偏低；`SKEW` 低的時候，未來波動反而偏高。這個方向和很多人對 `SKEW` 的直覺不太一樣，也提醒我們：**市場上「尾部風險溢價變高」這件事，不等於「明天就會更亂」。**

## 真正重要的是第二層：控制 VIX 之後還剩多少

研究上更關鍵的問題不是「它有沒有相關」，而是：

**如果 `VIX` 已經在模型裡，`SKEW` 還剩多少增量資訊？**

`K181` 的答案是：有，但很薄。

控制 `VIX` 之後，`SKEW` 對未來波動的部分相關在四個 horizon 都還有顯著：

- `1d` partial `r = -0.032`
- `5d` partial `r = -0.064`
- `22d` partial `r = -0.060`
- `66d` partial `r = -0.074`

這裡最值得注意的不是 p-value，而是 effect size。

這些數字的意思比較像：

> `SKEW` 不是完全重複 `VIX`，但它補進來的資訊非常有限。

如果你是做學術研究，這可以算是一個有趣的非零結果；但如果你是想找可落地的預測改進，這個幅度還遠遠不夠。

## 一進入 forecasting，SKEW 的優勢就消失了

K181 還做了更嚴格的 `GARCH-X` 檢查，也就是把 `SKEW` 當作外生變數，看看能不能改善基準模型。

結果並不支持。

雖然含 `SKEW` 的模型在樣本內 `R²` 多了大約 `0.0041`，但真正更重要的樣本外 loss 並沒有變好：

- `QLIKE GJR only = 0.6408`
- `QLIKE GJR + SKEW = 0.7101`
- `DM p = 0.2286`

白話講就是：

**加了 `SKEW` 之後，模型沒有變得更準，反而在這次比較裡還更差。**

而且這個差異沒有通過 `DM` 檢定，所以不能把它說成一個可靠改進。

這一步很重要，因為它把「樣本內有些訊號」和「實際預測真的更好」嚴格分開了。

## 拿去做 overlay，也沒有通過最終驗收

很多指標就算預測改進不大，還是可能在配置或風控層有用。所以 K181 又往前做了一步：把 `SKEW` 做成 `VT overlay`，看能不能優化既有的 `12/VIX` 類 baseline。

最好的規格是 `SKEW > 130` 時減碼 `30%`。它的表面結果看起來不差：

- baseline `Sharpe = 1.8307`
- best overlay `Sharpe = 1.8700`
- `MDD` 從 `-0.0772` 改善到 `-0.0498`

但關鍵不在表面數字，而在正式檢定。

這組最優 overlay 的：

- `Sharpe diff = 0.0392`
- `p = 0.0385`
- `harvey_pass = false`

也就是說，**它看起來有點進步，但還沒強到能通過研究系統設定的更嚴格門檻。**

這正是 K181 最誠實的地方：它沒有因為看到漂亮一點的 Sharpe 就直接宣稱成功。

## 這個結果真正教會我們什麼

K181 的價值，不是在證明 `SKEW` 完全沒用，而是在替它找到比較準確的位置。

這個位置大概是：

1. `SKEW` 反映的是和尾部保護需求有關的市場結構訊號。
2. 這個訊號和未來波動有關，控制 `VIX` 後仍留下一點殘差資訊。
3. 但這點資訊還不足以穩定改善 forecasting，也不足以讓交易 overlay 通過更嚴格檢定。

換句話說，`SKEW` 比較像是：

**一個值得觀察的輔助指標，而不是一個已經證明可單獨拿來升級策略的主信號。**

## 一般讀者可以怎麼理解

如果你平常會看市場風險指標，K181 給了一個很實用的提醒：

**不要把「有額外資訊」直接翻譯成「足以改變決策」。**

金融市場裡，很多變數都不是零，但真正稀缺的是那種：

- 不只樣本內顯著
- 控制已知強因子後還有增量
- 到樣本外還能改善 loss
- 放進策略後還撐得過正式檢定

`SKEW` 在 K181 這裡只過了前兩關，後兩關沒有過。

所以它比較像研究上的補充變數，而不是投資上的核心武器。

## K181 的一句話結論

**`SKEW` 對未來波動不是零資訊，但它沒有證明自己足以超越或穩定補強 `VIX`。**

這不是否定 `SKEW` 的存在價值，而是把它從「可能的新主角」放回更合理的角色定位。
