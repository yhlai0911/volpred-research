# 投機股和防禦股的波動率差，真的能提早預警市場風暴嗎？K151 的答案是否定的

有些市場故事一聽就很合理。

例如這個：

如果市場開始焦躁，投機型資產的波動率應該會先飆上去，防禦型資產的波動率比較慢。那麼，只要盯著兩者之間的差距，是不是就能提早看到風險正在累積？

`K151` 要驗的，就是這個很有行為金融味道的想法。

它把一組比較偏投機的資產：

- `ARKK`
- `BITO`

和一組比較偏防禦的資產：

- `XLP`
- `XLU`
- `GLD`

放在一起，計算「跨類別波動率離散度」這個指標，簡稱 `CSVD`，再看它能不能幫助預測 `SPY` 未來的波動率。

最後答案很清楚：

**這個信號有故事，但沒有增量。VIX 幾乎已經把它想提供的資訊吸收掉了。**

## 先講直覺：這個假說為什麼一開始看起來很合理

如果你把市場分成「敢冒險」和「想避險」兩邊，那麼在風險升高之前，兩邊的價格行為不會完全同步。

投機資產通常先變得不穩，防禦資產比較晚反應。從這個角度看，觀察兩者的波動率差距，確實像是在看市場內部溫差。

K151 用的就是這個設計。它不是直接拿單一資產的漲跌來猜未來，而是看：

> 市場裡不同風格資產之間的波動率分化，有沒有辦法提供 VIX 之外的額外訊號？

這個問題問得很好，而且也比單純追價格更細緻。

## 全樣本看起來有點東西，但那只是第一層

如果你只看大樣本相關性，`CSVD` 似乎不是完全沒用。

例如 `2015-01-01` 到 `2024-12-31` 這段資料裡，某些回歸確實顯示：

- `csvd_raw` 對未來 5 天 `SPY` 波動率的相關不低
- 樣本數也很大，`n = 2220`
- p-value 幾乎都是 `0`

如果停在這裡，很容易寫出一篇「行為金融找到新風險指標」的文章。

但 K151 沒有停在這裡。它繼續問了一個更重要的問題：

**這些相關性，在控制 VIX 之後還剩多少？**

## 一旦把 VIX 放進來，CSVD 的邊際價值幾乎消失

這是 K151 最核心的地方。

如果一個新指標真的有額外訊息，那它至少應該在控制 `VIX` 之後，還能保留一些穩定預測力。

結果不是這樣。

部分相關的結果顯示：

- `csvd_raw -> spy_vol_fwd5` 的原始相關雖然不低，但控制 `VIX` 後只剩 `0.1348`
- 有些規格甚至直接翻成負號
- 更重要的是，到了樣本外比較與策略測試，幾乎全部都站不住

K151 最值得記住的幾個結果是：

- `CSVD + VIX` 的樣本外 `R² = 0.281`
- `VIX` 單獨使用的樣本外 `R² = 0.285`
- 也就是說，**加了 CSVD 之後反而更差**

如果只看這個數字，其實已經夠了。

你可以把它理解成：

> 這個新指標不是完全沒訊息，而是它的那點訊息，對實務上真正要做的預測任務來說，沒有超出 VIX 已經提供的範圍。

## 更殘酷的是，做成策略不只沒加分，還扣分

很多信號在統計上會留下微弱痕跡，但只要一走進交易或配置層，就會原形畢露。

K151 這次也是。

它把 `CSVD` 拿來做 overlay，想看看能不能改善既有的 `12/VIX` 類型風控框架。結果：

- 原本 `12/VIX` 的 `Sharpe = 0.8022`
- 加上 `CSVD overlay` 後，`Sharpe = 0.7458`

也就是說，**不是沒幫助而已，而是把原本還不錯的東西弄得更差。**

這種結果在研究上很重要，因為它會提醒你：

一個指標就算看起來有經濟故事、有樣本內顯著、甚至控制其他變數後還留一點點關係，也不代表它適合拿來做決策。

## K151 最強的一刀：安慰劑測試

K151 還做了一個很關鍵的檢查，就是 placebo test。

簡單說，它把資產配對打亂、重抽很多次，看「你現在這個信號」到底比隨機亂湊出來的版本好多少。

結果非常直接：

**真實信號只排在第 39 百分位，p = 0.607。**

翻成白話就是：

> 你現在看到的這點效果，跟隨機拼出來的假信號幾乎沒有可區分性。

這一步很關鍵，因為它把很多看似有點用的「弱信號」直接打回原形。

## 這題最後到底學到什麼

K151 並不是說市場內部風格分化完全不重要。

它真正說的是：

1. **這種分化確實存在**
2. **樣本內也看得到某些統計痕跡**
3. **但一到樣本外、控制 VIX、或放進策略層，它就沒有額外價值**

這和很多行為金融題目很像。

故事通常都很好懂：

- 投機資產先躁動
- 防禦資產慢半拍
- 市場內部的裂痕能提早反映風險

但一旦你把最強的已知指標，也就是 `VIX`，一起放進模型裡，很多漂亮故事最後都會變成一句很樸素的結論：

**VIX 已經夠用了。**

## 一般讀者可以帶走什麼

如果你不是做研究的人，K151 至少有兩個值得記住的地方。

第一，**有故事不等於有增量。**

市場上最危險的一類內容，就是那些「講起來完全合理」但沒做過增量比較的信號。它們常常不是全錯，而是只是把已知資訊換個名字再講一次。

第二，**看一個新指標值不值得用，最好問兩件事：**

1. 控制 `VIX` 之後還剩下什麼？
2. 放進實際策略後，結果有沒有更好？

K151 的答案在這兩關都不理想。

## K151 最後留下的結論

K151 沒有推翻行為金融的直覺，但它清楚畫出了一條界線：

**跨類別波動率離散度可以拿來說故事，卻沒有提供超過 VIX 的實際預測價值。**

這不是一個華麗的發現，但它是一個很有用的 null result。因為它幫研究系統少走了一條看起來聰明、實際上增量接近零的路。

## 資料來源

- 實驗編號：`K151`
- 市場資產：`SPY`
- 投機組：`ARKK`, `BITO`
- 防禦組：`XLP`, `XLU`, `GLD`
- 期間：`2015-01-01` 至 `2024-12-31`
- 樣本外：`2020-01-01` 至 `2024-12-31`
- 關鍵結論：
  - `CSVD + VIX` 樣本外 `R² = 0.281`
  - `VIX alone` 樣本外 `R² = 0.285`
  - overlay `Sharpe` 從 `0.8022` 降到 `0.7458`
  - placebo `p = 0.607`
  - verdict `= NULL`
