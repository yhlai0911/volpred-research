# 十年又十年：同一套策略在五個年代怎麼表現？

「過去十年很賺」不一定代表「下一個十年也會賺」。一套策略真正的考驗，不是它在某段牛市跑得多快，而是把它丟進**不同的年代**——金融海嘯、QE 印鈔、低波多頭、疫情升息——它能不能持續站在場上。

K319 把 SPY 的 22 年（2004-11 至 2026-03）切成五個年代，用同樣四套策略一視同仁地跑一次。沒有重新最佳化、沒有為哪個時期挑參數，就是把同一個規則套到每個年代，看看結果攤開來長什麼樣。

## 四個對照組

- **SPY 買入持有**：100% 押在標普 500，最直白的對照組。
- **50/50 股金配置**：一半 SPY、一半黃金（GLD），每月再平衡。
- **50/50 + VT 公式**：股金各半之上，加一層「**12 / VIX**」的波動率目標——VIX 越高，倉位越輕。
- **50/50 + VT 階梯**：同樣是波動率目標，但用一個簡單的階梯規則（VIX < 12 滿倉、12-15 八成、15-20 六成…依此類推）。

訊號是月初 VIX，套用到當月報酬，沒有偷看未來資料。

## 五個年代的表現一覽

| 年代 | SPY B&H Sharpe / MDD | 50/50 Sharpe / MDD | VT 公式 Sharpe / MDD | VT 階梯 Sharpe / MDD |
|---|---|---|---|---|
| 2005–2009（金融海嘯） | 0.14 / **−55.2%** | 0.70 / −32.5% | 0.93 / −12.7% | **0.96** / −13.0% |
| 2010–2014（QE 復甦） | **0.98** / −18.6% | 0.74 / −13.1% | 0.60 / −10.4% | 0.65 / −8.8% |
| 2015–2019（低波多頭） | 0.88 / −19.4% | 1.03 / −11.6% | 0.97 / −9.5% | **1.04** / −8.4% |
| 2020–2024（疫情+升息） | 0.75 / −33.7% | 0.98 / −20.3% | **1.03** / −11.1% | 1.00 / −9.9% |
| 2025–2026（當前） | 0.64 / −18.8% | **1.79** / −12.0% | 1.94 / −7.5% | 1.93 / −7.2% |
| 完整 2004–2026 | 0.62 / −55.2% | 0.88 / −32.5% | 0.95 / −12.7% | **0.97** / −13.0% |

註：每列粗體是 Sharpe 該年代最高者；MDD 是最大回撤、越接近 0 越好。

### 圖 1：Sharpe 與最大回撤逐年代對照

![Sharpe 與 MDD 各年代比較](experiments/k319/figures/fig1_sharpe_mdd_by_decade.png)

左邊 Sharpe 看「每承擔一單位風險換到多少報酬」，右邊 MDD 看「最壞情況虧多少」。VT 兩個版本（橘、綠）的 MDD 在**每個年代都比 SPY 與 50/50 來得淺**——這是 K319 唯一不打折扣的結論。

### 圖 2：CAGR 熱圖

![CAGR 熱圖](experiments/k319/figures/fig2_cagr_heatmap.png)

年化報酬的故事就複雜多了。2005-2009 SPY 只有 0.49% CAGR，因為一場金融海嘯把前面幾年漲幅幾乎吃光；同期 50/50 配置卻交出 11.25%。2010-2014 風雲倒轉，SPY 14.98% 回敬一切「分散投資」教條。沒有一列是穩贏的綠色。

### 圖 3：最慘一個月損失

![最慘月損失](experiments/k319/figures/fig3_worst_month_by_decade.png)

2008-10 那一根，SPY 單月 −16.5%、50/50 −15.4%，VT 公式 **−4.7%**。這不是回測魔法，是 2008 年 10 月 VIX 月初已經破 40，VT 訊號當月直接把倉位砍到 30%——進場的部位本來就少。

## 真正的看點：四件事

**1. VT 不是「永遠贏」。** 在 2010-2014 這種風平浪靜的 QE 復甦年代，VT 的 Sharpe（0.60、0.65）反而**輸給** SPY 買入持有（0.98）。原因簡單：那段期間 VIX 平均偏低、股市單向漲，把倉位調輕等於少賺。**「全天候策略」這個詞在 K319 沒有任何一檔當得起**——四套策略沒有一個在五個年代都拿 Sharpe 第一。

**2. 但 VT 在「保命」這件事上沒輸過。** MDD 維度，VT 公式與 VT 階梯**每個年代**都比兩個買入持有版本淺。22 年完整期間，SPY 最大回撤 −55%、50/50 −32%、VT 兩版都只有 −13% 上下。平均 MDD 改善約 8.5 個百分點。

**3. 公式 vs 階梯沒有顯著差別。** 兩者完整期間 Sharpe 差 0.03、各年代互有勝負。這很有意義：代表「**12/VIX**」這個連續公式並沒有比一個直覺的階梯規則高明多少，過度精細化參數反而沒必要。

**4. 2025-2026 的數字漂亮但要打折。** 這段只有約一年資料，Sharpe 1.93 看起來驚人，但放在 22 年的脈絡裡，它只是其中一個低 MDD、高報酬同時出現的子區間，不能單獨外推。

## 那這套策略到底適合誰？

K319 的攤開方式提醒一件事：**選策略要看你怕什麼**。

- 若你最怕的是「再來一次 2008」、不想看著帳戶腰斬，VT 風格在五個年代都把最大回撤壓在 −13% 上下；報酬會比 SPY 慢一點、但不會把你淘汰。
- 若你接受得了 −30% 以上的回撤、相信長期向上，純 SPY 的累積報酬（22 年 +726%）仍贏過 VT 兩版（+346% / +383%）。
- 若你想在報酬與風險間找平衡，50/50 在多數年代是相對穩定的中間路線——但別忘記它在 2008 年照樣 −32%。

沒有哪一條路是免費午餐。**選擇權在「你願意承擔哪一種痛」這件事上**，K319 的歷史紀錄只是把每條路會痛在哪、痛多久攤開來給你看。

## 方法論註記

- 資料：yfinance（SPY、GLD、^VIX），日資料 2004-11-18 至 2026-03-24，共 5,369 個交易日。
- 訊號使用月初 VIX，套用到當月報酬，無前視（lookahead）汙染。
- 50/50 配置每月再平衡。
- 「2025-2026 (Current)」僅 1 年多資料，數字僅作參考、不可單獨外推。
- 完整代碼與結果：`experiments/k319/k319_decade_table.py` + `k319_decade_results.json`。
