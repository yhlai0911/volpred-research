## 誠實邊界

- `effectful` 是**下界**（`mutating_command` 用保守白名單，會寫檔但沒命中 pattern 的
  腳本被算成 read_only）；`noop`／`read_only` 是**上界**。
- 部門歸屬是**啟發式**：以 tool input 內出現的部門名計數推斷，不是權威來源。
  Claude Code 的 project 目錄由 cwd 決定，七個部門 pane 都在主 checkout，
  telemetry **沒有**部門欄位。要精確歸屬需要在 pane 啟動時把部門寫進 session metadata
  ——這是一個尚未存在的機制，本報告不假裝有。
- 停擺窗邊界 15:50–18:46 採用經理給定值，未獨立驗證 provider 拒絕的實際起訖。
- Codex 「零用量」是「telemetry 內沒有 rollout 記錄」，不等於「Codex 沒被呼叫」；
  若有呼叫但沒落檔，那是另一個缺陷（本輪未查）。
- 兩次全窗掃描的今日總量 4,641,188（19:23:10）與 4,734,619（19:2x 第二次掃描）差在
