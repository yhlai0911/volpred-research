\section*{2.\ Round~1 Medium Issues: Verification}

\subsection*{\textcolor{errorred}{M1 [NOT FIXED]: Table~4 TAIFEX VaR row uses PRG Basic, labeled PRG Extended}}

Round~1 identified that Table~4 reports TAIFEX (PRG Ext) with VR = 0.95\%, Kupiec $p$ = 0.88, Basel Green. Verification against K874d:

\begin{itemize}[nosep]
\item \textbf{K874d PRG Extended}: VR = 0.237\%, Kupiec $p$ = 0.008, Basel Green. \textcolor{errorred}{Does NOT match Table~4.}
\item \textbf{K874d PRG Basic}: VR = 0.949\%, Kupiec $p$ = 0.881, Basel Green. \textcolor{okgreen}{Matches Table~4 exactly.}
\end{itemize}

The TAIFEX VaR numbers in Table~4 still correspond to PRG \emph{Basic}, not PRG \emph{Extended}. This is a labeling error. Moreover, the actual PRG Extended VaR for TAIFEX is \emph{too conservative} (VR = 0.24\%, Kupiec rejects at $p = 0.008$), which would weaken rather than strengthen the VaR narrative if corrected. The recommended fix is either:
\begin{enumerate}[nosep]
\item Relabel the row as ``PRG Basic'' and note that PRG Extended is too conservative on TAIFEX, or
\item Use Student-$t$ quantiles for PRG Extended VaR (which would likely produce a better-calibrated VR), or
\item Present both PRG Basic and PRG Extended VaR results for TAIFEX.
\end{enumerate}

\subsection*{\textcolor{okgreen}{M2 [FIXED]: PRG innovation distribution specified}}

Section~2.2 now explicitly states: ``We assume $r_n | \mathcal{F}_{n-1} \sim N(0, h_n)$; all parameters are estimated by maximizing the Gaussian quasi-log-likelihood, which produces consistent estimates even under non-Gaussian innovations (Bollerslev and Ghysels, 1996).'' \textcolor{okgreen}{Clear and well-justified.}

\subsection*{\textcolor{warncolor}{M3 [PARTIALLY ADDRESSED]: Contribution~2 scope}}

The introduction (line~62) still frames Contribution~2 as ``develops a fair comparison framework.'' While Section~4.1 correctly presents the HAR-vs-GJR finding as specific to TAIFEX (DM $t = 0.57$), the introduction's framing remains broad. The body text handles nuance well, but an FRL reviewer may find the introduction's claim overstated given that for the five OHLC markets, GJR significantly beats HAR on the common target. Suggest softening to ``applies a fair comparison framework'' or ``demonstrates that target choice can reverse model rankings.''

\subsection*{\textcolor{warncolor}{M4 [NOT FIXED]: Log-likelihood not provided}}

The paper still does not write the quasi-log-likelihood function explicitly. While the description ``Gaussian quasi-log-likelihood'' is clear to specialists, including the one-line formula $\ell = \sum_n [-\frac{1}{2}\log h_n - \frac{r_n^2}{2h_n}]$ would aid reproducibility with minimal space cost. This remains a minor-to-medium issue for FRL.

\subsection*{\textcolor{okgreen}{M5 [FIXED]: Separate GARCH leverage clarified}}

Section~2.3 now reads: ``\textbf{Separate GJR}: independent GJR-GARCH(1,1) models for each session with leverage terms but no cross-session linkage.'' This resolves the confound concern: both PRG Extended and Separate GJR include leverage, so the PRG-vs-Separate comparison cleanly isolates the cross-session bridge. \textcolor{okgreen}{Well done.}

\subsection*{\textcolor{okgreen}{M6 [FIXED]: Orphan bibliography entries removed}}

All four orphans identified in Round~1 have been removed. The bibliography now contains exactly 19 entries, all of which are cited in the text. A full audit confirms zero orphans and zero missing entries. \textcolor{okgreen}{Clean.}

\subsection*{\textcolor{warncolor}{M7 [NOT FIXED]: EEM VaR too conservative}}

Table~4 still reports EEM (PRG Ext) VR = 0.40\%, Kupiec $p < 0.01$, ranked ``1st.'' The Kupiec test \emph{rejects} the null hypothesis that VR = 1\% because the model is too conservative---it produces too few violations. From K881, the EEM PRG Extended 1\% VaR has only 7 violations in 1,734 days (VR = 0.40\%). The 5\% VaR also rejects (VR = 3.46\%, 60 violations, Kupiec $p = 0.002$).

Section~4.3 (line~257) claims: ``The consistent ranking---PRG Extended $>$ PRG Basic $>$ Separate $>$ GJR $>$ HAR---holds across all six markets for both VaR and ES evaluations.'' This is overstated: for EEM, the PRG Extended VaR is \emph{not well-calibrated} at either the 1\% or 5\% level. A model that rejects Kupiec because it is too conservative should not be ranked above models that pass. At minimum, add a footnote acknowledging EEM's over-conservatism.

\subsection*{\textcolor{okgreen}{M8 [PARTIALLY ADDRESSED]: Asymmetric refit frequencies}}

Section~2.3 now includes ``(reflecting higher estimation cost)'' as a brief justification for the 126--252 day refit frequency for PRG. This is minimal but acceptable for FRL. A sensitivity analysis with equal refit frequencies would be ideal but is not strictly required for the letter format.

\subsection*{Minor Issues (Optional Fix)}

\begin{enumerate}[label=\textbf{m\arabic*}]

\item \textbf{Log-likelihood function.}
Carried from Round~1 M4. Adding the one-line Gaussian quasi-log-likelihood formula ($\ell = \sum_n [-\frac{1}{2}\log h_n - r_n^2/(2h_n)]$ plus constant) would cost one line and improve reproducibility. Not strictly required for FRL but recommended.

\item \textbf{Contribution~2 framing.}
Carried from Round~1 M3. The introduction still says ``develops a fair comparison framework'' which is slightly overstated since the framework itself is Patton (2011) / Hansen and Lunde (2005), and the key finding (HAR$\approx$GJR on common target) is specific to TAIFEX. The body text handles this well; a minor softening in the introduction (e.g., ``applies'' instead of ``develops'') would align the framing.

\item \textbf{$\rho$ dual usage.}
Carried from Round~1 m2. $\rho_s$ denotes persistence while Spearman $\rho$ appears in Table~2. Consider $\rho^{\text{Sp}}$ for the latter.

\item \textbf{Overnight--intraday return correlation.}
The additivity assumption $\sigma^2_{\text{full}} = r^2_{d,0} + r^2_{d,1}$ relies on zero correlation between session returns. Reporting the sample correlation (expected to be near zero) would reassure readers.

\item \textbf{Transaction costs in VT strategy.}
Section~4.4 acknowledges this limitation but draws strong conclusions (``64\% improvement''). Even a rough adjustment (2~bps $\times$ average turnover) would be helpful.

\end{enumerate}
