\subsection*{\textcolor{fixedblue}{S3. Internal gamma inconsistency (Section~4.5 vs Table~2) --- PARTIALLY RESOLVED}}

\textbf{R1 status:} Section~4.5 reports 0050.TW $\gamma = 0.124$ ($t = 2.46$) and TSMC $\gamma = 0.054$ ($t = 1.07$), contradicting Table~2's values.\\
\textbf{R2 status:} K892 reveals the likely explanation.

\medskip
\noindent\textbf{Diagnosis from K892:}
\begin{itemize}[nosep]
\item Section~4.5's 0050.TW $\gamma = 0.124$ is closest to the rolling $w=2000$ mean ($\gamma_{\text{mean}} = 0.106$, $\gamma_{\text{median}} = 0.103$) or possibly a specific rolling window.
\item Table~2's $\gamma = 0.087$ is closest to the 2009--2023 expanding estimate ($\gamma = 0.083$).
\item Section~4.5's TSMC $\gamma = 0.054$ matches K892 full-sample ($\gamma = 0.052$) better than Table~2's $\gamma = 0.039$.
\end{itemize}

The inconsistency arises from using different estimation windows in different sections without disclosure. K892 data makes it possible to use a \textbf{single, consistent specification throughout}.

\noindent\textbf{Text changes required:}
\begin{enumerate}[nosep]
\item Choose one specification (full-sample Normal recommended) and use it in \textbf{both} Table~2 and Section~4.5.
\item If Section~4.5 intentionally uses a different window (e.g., rolling $w=2000$), state this explicitly with a footnote explaining why.
\end{enumerate}

\textbf{Severity:} \textcolor{fixedblue}{Downgraded from SEVERE to MEDIUM} (will be automatically resolved when S2 is addressed).
