## Data Processing Notes

- BTC daily return: `log(P_t / P_{t-1}) × 100` from `btc_usd_adj_close`
- SPY daily return: `log(P_t / P_{t-1}) × 100` from `spy_adj_close`
- VIX 進模型作為 t-1 lagged regressor（per K1025 signal.shift(1)）
- BTC realized volatility (RV)：rolling 22-day std × sqrt(252) annualized
- BTC absret: `|BTC_return|` 用作 absorption proxy
- Asymmetric Granger: 分位回歸用 lower (q=0.25) / upper (q=0.75) tail
- 週末 BTC 資料因 SPY/VIX 無對應交易日 forward-fill 或 dropna 視 experiment 而定（K1025 uses dropna union）

`paper/crypto-fear-channel/reproduce.py` reads `experiments/k1025/k1025_results.json`（stored output, not live yfinance）作為 paper claims 對照。生成 K1025 results 的 source script `experiments/k1025/k1025.py` 預設 live-fetch yfinance，未來 R1 / final submission 階段建議改讀 `paper/crypto-fear-channel/data/spy_btc_usd_vix_2015-2026.csv` snapshot 確保 byte-match reproducibility（per paper-workflow.md hard rule 1）。

**To regenerate snapshot** (e.g. R1 reviewer requests updated data):
```bash
uv run python scripts/snapshot_yfinance.py \
  --ticker SPY,BTC-USD,VIX \
  --start 2015-01-01 \
  --end <new-end-date> \
  --paper crypto-fear-channel
```
更新 `data/` CSV 後須重跑 K1025 + reproduce gate verify match_rate ≥95%。
