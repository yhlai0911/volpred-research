**日期**：2026-08-05（**v2 — 修正版**）
**來源**：老闆 Telegram（`telegram-1605`）—— 「有沒有辦法在我們volpred平台上建立這樣子的完整功能／然後像他這樣 應用自己的功能來寫分析文章作為行銷」

> **v1 撤回**。第一版有兩個實質錯誤，都是我沒實地查證就下的判斷，老闆當場指出：
> 1. 我寫「VolPred 有能檢查讀者投組的工具，只要加 CTA」——**五個工具沒有一個接受讀者的持倉**。
> 2. 我寫「VolPred 定價比 YP 貴」——我拿的是 Substack 文章裡的折扣價。**列表價完全相同（299 / 599）**。
>
> v1 的建議（「半天加 CTA 就好」）建立在第 1 個錯誤上，連到一個回答不了讀者問題的工具比不連更糟。以下是實地看過 YP 全站後的重寫。

---

## 1. YP 實際上是什麼（實地查證，非文章推論）

**25 個 premium 工具**，不是一兩個計算器。全部同一個形狀：**輸入你自己的決策 → 拿歷史資料回測／模擬 → 給你成功率**。

- 投組類：Portfolio Visualizer（台英美三市場）、自訂資產組合、效率前緣、股票相關性、再平衡試算
- 退休類：4% 法則回測、退休提領回測（**9 種提領策略、150+ 年資料**）、蒙地卡羅提領模擬、投資組合退休提領 PK、報酬順序風險
- 個人財務：**個人現金流量表**、**個人資產負債表**、房貸選擇計算機、房貸安全網回測、借貸/增貸投資勝率
- 迷思驗證：修正後前瞻報酬分析、留現金等跌的機會成本量化、逢低加碼 vs 固定配置、錯過最佳漲幅

### 兩個值得學的設計

**(a) 付費牆切在「市場涵蓋」，不切在「功能存在」**

| | Free | Premium | Premium Plus |
|---|---|---|---|
| Portfolio Visualizer | **台股** | 台英美股 + 匯率 | 台英美股 + 匯率 |
| 觀察名單 | 20 | 200 | 200 |
| 退休提領/蒙地卡羅 | — | — | ✓ |

免費用戶能**完整體驗**工具（用台股），撞牆的時機是他想看美股的那一刻。不是把功能鎖起來讓人猜。

**(b) 訂閱頁是為「從文章／工具結果頁進來的人」設計的**

原文寫著：

> 「如果你是從文章或工具結果頁進來，最重要的問題通常不是『有哪些功能』，而是**我該用哪個方案解決眼前的決策**。」

所以那頁的第一段不是價目表，是「**先從你的問題開始：你是哪一種使用者？**」，四個決策情境各自導向一個方案。漏斗在頁面結構裡是明寫出來的。

## 2. VolPred 實際上是什麼（修正後）

| 工具 | 實際做什麼 | 吃使用者輸入嗎 |
|---|---|---|
| VT 保險計算器 | 問 3 個問題（承受力／反應／期限）判斷你需不需要 VT | 吃**偏好**，不吃持倉 |
| 12/VIX 計算器 | 展示固定配置（50/50 SPY/GLD 或 SPY only）的策略機制 | 否 |
| 風險預報 | **6 個**固定標的的 VaR/ES，金額以假設的 $1,000,000 計 | 否 |
| 策略選擇器 | 問 3 個問題推薦策略 | 吃偏好 |
| 指標競技場 | 我們自己的預測戰績排名 | 否 |
| `/portfolio` | **是 VolPred 自己的 paper-trading 追蹤**（re-export `admin/paper-trading`） | 否 |

**沒有任何工具接受讀者的持倉。** 資料面：無自建價格庫，靠 yfinance 即時抓；風險預報只涵蓋 6 個標的。

這是**產品類別的差異，不是功能數量的差異**：
- YP＝個人理財規劃工具箱（「**我**這樣做行不行」）
- VolPred＝波動率研究平台（「**我們**研究發現什麼」）

---

## 3. 但我們有一樣 YP 完全沒有的東西

翻完 YP 的 25 個 premium 工具與完整功能對照表：**沒有任何波動率或風險建模**。沒有 VT、沒有 GARCH、沒有 VaR/ES、沒有 regime 判別、沒有尾部相依。

他們的回測全部是「歷史報酬序列 + 提領規則」。**風險這一整面是空的。**

而那正好是 VolPred 唯一有的東西 —— GJR-GARCH、VT、VaR/ES、Basel 檢定、尾部相依、1,743 篇實證文章、12 篇論文在背書。

所以「像他那樣做」有兩條路，差別很大：

**路線 A：複製 YP 的工具箱** — 要自建台英美價格庫、150+ 年歷史資料、通用回測引擎、20+ 個工具。這是**重造一個他們已經領先數年的產品**，而且退休提領是他們的主場。**不建議。**

**路線 B：做他們做不了的那一個** — 讓使用者輸入自己的持倉，跑我們的波動率風控機器，回答兩個 YP 永遠答不了的問題：

> 「**你這個投組，最壞會有多壞？**」（GJR-GARCH + VaR/ES + 尾部相依，不是歷史最大回撤）
> 「**VT 對你這個投組有沒有用？**」（我們有 K738 等實證：VT 每年成本 2–3.5%，而 50/50 SPY/GLD 免費拿到 19.6pp MDD 改善）

這才是 VolPred 形狀的產品：**個人化的入口 + 我們既有的研究引擎**。缺的只有「使用者輸入層」，引擎已經在跑了。

## 4. 真實成本（修正）

| | 工作 | 規模 | 說明 |
|---|---|---|---|
| **B1** | 投組輸入層：使用者輸入標的+權重，存檔需登入 | **1–2 週** | 會員系統已有；需 ticker 驗證與 yfinance 取價的快取層 |
| **B2** | 把風險預報從 6 個固定標的改成吃任意投組 | **1–2 週** | GARCH/VaR 引擎已有，改的是輸入與批次取價 |
| **B3** | 「VT 對你有沒有用」個人化判定 | **1 週** | K738 等結果已在；把 gamma 問卷接上實際持倉 |
| **B4** | 示範文章：用 B1–B3 跑具體投組，輸出當文章證據 + CTA | 1–2 天/篇 | 依賴 B1–B3 |
| **B5** | 付費牆定位（比照 YP 切法：免費限台股或限標的數） | 3–5 天 | 依賴 B1 |

**約 5–7 週**做到「文章 → 個人化工具 → 訂閱」這條線第一次真的存在。

v1 說的「半天加 CTA」是錯的 —— 沒有可導的目的地。

## 5. 需要你決定

1. **走路線 B 嗎？** 若要，B1–B3 是實質開發，不是設定調整。
2. **金流何時開？** 已建好（ECPay adapter、19 測試、簽章釘官方向量），關著是你 2026-07-04 的指示。建議 B1–B3 上線、有真實使用數字後再開。
3. **免費牆切哪裡？** YP 切「市場涵蓋」很聰明。我們可切「標的數」或「歷史深度」，但這是產品決策。
