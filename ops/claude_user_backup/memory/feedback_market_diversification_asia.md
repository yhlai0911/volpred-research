- 挖題端：research-topic-discovery 每 batch ≥2 條非美股方向（含 Pacific-Basin FJ / JIMF 等亞太期刊線）
- 資料：yfinance smoke test 2026-07-15 驗證 38/40 — 台股產業代表股✅、^N225+日股產業✅、^NSEI/^BSESN/**^INDIAVIX**✅、^STI/^JKSE/^KLSE/^SET.BK✅；^NKVI ❌（日經VI 無源）、^PSEI ❌（用 EPHE proxy）、越南用 VNM proxy
