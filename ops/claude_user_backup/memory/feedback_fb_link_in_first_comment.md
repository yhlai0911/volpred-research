用戶 2026-06-08 重話糾正：「妳他媽的 妳不知道FB貼文正文中不能放連結嗎」。

**硬規則**：FB 貼文**正文 (body) 絕對不放外部連結**。FB 演算法會壓低含外部連結的貼文觸及（視為想把用戶導離 FB）。

**正確做法**：
1. 正文 = 純文字 hook（anti-AI-style，per [[feedback_fb_opening_no_friend_asked]]），**不含任何 URL**。
2. 連結放**第一則留言**（comment），發完正文後馬上自己留言貼 URL。
3. 若想要連結預覽卡：可在正文先含 URL 生成預覽卡 → 再編輯刪掉正文 URL（卡通常會留）→ 連結仍放第一則留言。但最安全是正文完全無連結、連結只在留言。

**Why**：觸及 = 漏斗入口（Mission #5 曝光流量）。正文放連結 = 自廢觸及 = 違反平台運營目標。

**2026-06-08 incident**：我發 mile_22d52561 到 Ivan Lai FB 時把 `https://volpred.zeabur.app/...` 放在正文最後一行 → 用戶震怒。已修：編輯該貼文移除正文連結 + 連結改放第一則留言。
