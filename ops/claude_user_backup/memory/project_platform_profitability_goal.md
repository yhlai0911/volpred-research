**Fact**: volpred-research 平台的 ultimate goal 是**商業盈利**，不只是學術產出。5-mission（文章/實驗/論文/平台運營/曝光流量）都是 means to that end。

**Why**:
- 用戶 2026-05-12 明確補充：「最終目標就是這平台可以盈利」
- 在此之前 CLAUDE.md 的 Mission/Vision 寫的是「最受信賴、最受歡迎」+ 5 個方向目標，但**沒有明說盈利是 ultimate**。用戶補完後，所有決策權重要重新校準
- 學術產出（paper / experiments）+ 內容輸出（feed articles / strategy listings）+ 平台運營（網站可用 / 排序公正）是**為盈利服務**的，不是反過來

**How to apply**:
1. 任何 task prioritization 加問一層：「這對 monetization 有何貢獻？」
   - 直接貢獻：付費會員轉換、廣告/合作收入、策略授權、付費 API
   - 間接貢獻：曝光流量（→ 廣告 + 轉換池）/ 學術權威（→ 機構合作 / 顧問收入）/ 內容深度（→ 留存 + 口碑 + paid newsletter）
   - 無貢獻：純內部 refactor / 與用戶無接觸的 ops chore — 仍要做但 priority 下調
2. 文章寫作（M1）priority 應該加重 SEO + share-friendliness + 引流到付費漏斗
3. 論文（M3）的商業價值：學術權威 → 機構信任 → 顧問/演講/教學收入 + paid premium tier 的「研究背書」感
4. 平台運營（M4）排序應考量 conversion funnel：頁面速度 / 引導註冊 / 付費資訊 visibility
5. 新方向決策時除研究價值外加問：「這條 line 6-12 個月內有什麼可商業化的 deliverable？」
6. 既有的「研究誠實原則」不能因盈利目標讓步 — 反過來：研究誠實是長期商業價值的護城河
