用戶提醒：「樣本期間要用夠長」。

**Why:** 短期 OOS（如 2023-2024 只有牛市）無法涵蓋空頭狀態，結論可能不穩定。

**How to apply:**
- TAIFEX 日盤數據從 2012 起可用（14 年）→ 日盤 RV 可用更長樣本
- TAIFEX 夜盤從 2017/05/16 起（9 年）→ 全天 RV 上限 9 年
- OOS 應盡量含至少 1 次空頭（2018 或 2020 或 2022）
- 如果只有 2 年 OOS，至少做 Cross-OOS 多期間驗證
- 不要只在牛市期間評估策略然後宣稱有效
