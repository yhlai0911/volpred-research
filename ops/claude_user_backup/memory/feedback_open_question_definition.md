Open Question = 大問題、大方向（需要多個實驗才能回答的研究方向）。
小實驗疑問放 thinking/knowledge，不放 open questions。

**Why:** 用戶明確指出 open question 的定義是「大問題」。解決過程是：大問題 → 分解多個小實驗 → 每個實驗產出 feed 文章 → 最後整合寫統合文章（Q&A article）來回答大問題。之前放了太多小的實驗性疑問（如「EVT-VaR 為什麼失敗」「CF-VaR divergence」），這些應該放 thinking 或 knowledge。

**How to apply:**
- 新增 open question 前問：「這是一個需要多個實驗才能回答的大方向嗎？」
- 如果是 → open question
- 如果只需一個實驗或是技術細節 → thinking/knowledge
- 回答 open question 時：整合所有相關 feed 文章，寫一篇統合文章
