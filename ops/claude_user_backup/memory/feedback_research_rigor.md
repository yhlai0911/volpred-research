研究過程中必須持續自我質疑，直到被證據說服。

**Why:** 用戶指出我多次過早宣布「重大發現」（如 U-shape QLIKE），但跨期驗證後發現結論不穩固。快速取樣（every 5th day）得到的結論和完整分析不同。

**How to apply:**
1. 一個 OOS 期間的結果不能改變結論。必須跨至少 3 個不同期間驗證。
2. 宣布發現前問：「這在其他時期成立嗎？」「能實際操作嗎？」「有前瞻偏誤嗎？」
3. GARCH 樣本數不能太少——文獻建議 ≥500 (Hwang 2006), ≥1000 (Ng & Lam 2006)。SPY 有 8000+ 天數據，不要只用 504。
4. 與用戶討論中產生的洞見必須立刻存入知識庫或相關檔案，不能只在對話中說過就算。
5. Skill 存放可重用的方法論，研究結果存放在 research_program.md 和 references/。
