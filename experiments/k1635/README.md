# K1635 — 投資迷思驗證：「台積電打噴嚏、台股重感冒」

**一句話結論（reader-facing angle）**：台積電當天重跌，台股當天確實一起「重感冒」——但那有相當一部分是「台積電本來就佔指數約三分之一權重」的**算術**，再加上市場情緒真的擴散到其他股票；然而「**隔天繼續病**」其實是迷思，指數當天就把壞消息消化完，隔天方向上反而略偏（不顯著的）反彈。真正該留意的是：**接下來一週，整體波動會明顯放大**。

---

## 動機（Mission #2 研究護城河 + Mission #1/#5 高共鳴台灣讀者議題）

「台積電打噴嚏、台股重感冒」是台灣投資圈的口頭禪。它其實暗含三個層次的命題：
（1）**集中度**——台積電（2330.TW）在加權指數（TAIEX / ^TWII）的權重高到「一家獨大」；
（2）**方向傳導**——台積電重跌會拖累整個大盤（當天 + 隔天）；
（3）**波動傳導**——台積電的震盪會讓整個市場跟著不安。

這是台灣讀者最有共鳴的題目之一，且能實測、能證偽。學術上對應三條文獻脈絡：
- **Index concentration risk**：單一成分股權重過高使指數報酬被個股主導、分散化失效（如 S&P500 "Magnificent 7" 集中度討論、MSCI 單一成分上限規則的動機）。台灣的 TSMC 集中度是全球主要股市中最極端者之一。
- **Single-stock → index spillover / co-movement**：龍頭股 idiosyncratic shock 是否外溢為市場層級的共同波動（beyond 機械權重）；相關於 Barberis-Shleifer-Wurgler (2005) 的 co-movement、以及 lead-lag / information diffusion 文獻。
- **Event study of large idiosyncratic drops**：以個股極端負向事件為條件，檢視市場的當日反應、次日漂移（drift / reversal）與波動叢聚（Engle volatility clustering、event-conditioned realized vol）。

本平台既有知識庫已涵蓋多個 TSMC / 台股相關結果（見下方差異化），但**沒有**任何一條直接把這句俗諺拆成「2330 大跌 → 大盤條件傳導 event study + 集中度演變」來檢驗——K1635 補上這一塊，並刻意分離「機械成分 vs 真實外溢」。

## 方法（M1–M4）

### M1 集中度（近似法，**非官方 TWSE 指數權重**）
- **絕對市值成長**（無假設）：2330 市值 = raw Close × 股數。
- **權重近似序列（anchored proxy）**：`w(t) = mktcap_2330(t) / TAIEX(t)`，正規化使序列末端 = 文獻/公開資訊的 TSMC TAIEX 權重（中心 anchor **0.36**，另做 0.30 敏感度）。
- **假設與偏誤揭露（誠實原則）**：此 proxy 假設「全市場總市值 ∝ TAIEX 指數點位（除數常數）」。實際上指數除數會隨新上市成長，故**常數除數會系統性誇大權重上升幅度**。因此：
  - 主證據以**絕對市值成長**（無假設）呈現；
  - 權重軌跡以**公開資訊佐證**（TSMC 佔 TAIEX 約：2015 ~16-18%、2020 ~28%、2024-2025 ~30-38%）；
  - anchored proxy 僅作**趨勢形狀的視覺化**，並在圖與 JSON 明標其近似性與偏誤方向。

### M2 傳導強度（**同日 vs 隔日分離**）
- 大跌事件：`r_2330(t) ≤ -3%` 與 `≤ -5%` 兩門檻。
- **同日（contemporaneous）**：事件日當天 `r_TWII(t)` 的 P(下跌)、平均報酬、bootstrap CI。**明確標註含機械成分**（2330 是指數成分股，權重 ~35% → 大跌會機械性拖累指數 ~權重×跌幅），不當成「預測」宣稱。
- **隔日 T+1（純預測，無機械成分）**：事件日**之後一天** `r_TWII(t+1)` 的 P(下跌)、平均、CI。
  - **Lookahead 防護**：以 `r_twii.shift(-1)` 將隔日報酬對齊到事件日 t（signal=2330 在 t 日已收盤的大跌，target=指數 t+1 報酬）。已用合成資料驗證 `r_twii_next[t] == r_twii[t+1]` 且大跌日正確對應「其後一日」報酬，無 off-by-one、無洩漏未來。
- **檢定（vs 補集非事件日，避免子集混入母體）**：two-sample proportion z-test（P 下跌）+ Welch t（平均報酬）+ bootstrap 95% CI（`np.random.seed(42)`, 10,000 reps）。同日/隔日各自對照。

### M3 β / 迴歸
- **全期 OLS**：`r_TWII = α + β·r_2330`，HAC（Newey-West, maxlags=5）穩健標準誤。
- **Rolling 252 日 β**：時間演變。
- **Asymmetry #1**：下跌日（r_2330<0）β vs 上漲日（r_2330≥0）β，兩獨立子樣本 z-test（兩組日期互斥 → 獨立近似合理）。
- **Asymmetry #2（尾部放大）**：交互項迴歸 `r_TWII = α + b·r_2330 + c·(r_2330×大跌dummy) + d·大跌dummy`，HAC 檢定 `c`。

### M4 波動傳導
- 每個事件日 t 計算 ^TWII 之 **forward 5 日 realized vol**：`std(r_TWII[t+1..t+5])×√252`（年化）。
  - **Lookahead 防護**：window `rt[i+1:i+1+5]` 嚴格在事件日之後，不含事件日自身（合成資料已驗證）。這是「條件在事件 → 觀察其後波動」的合法 forward 研究。
- 事件組 vs 補集（非事件日）：bootstrap CI + Welch t on log-RV（波動右偏，log 較穩健）+ Mann-Whitney U（單尾：事件組>對照）。

### 防錯規則落實
- ✅ Lag 寫在代碼（`.shift(-1)` 對齊 + forward window 切片），非靠記憶；合成資料單元驗證。
- ✅ Baseline 與條件組同一報酬序列、同 lag 慣例；補集對照避免子集混入。
- ✅ 所有 bootstrap 固定 seed 42。
- ✅ 同日/隔日、機械/實證分離報告，結論強度不超過證據。
- ✅ 小樣本（-5% 僅 N=15）誠實報告 N 與 power 限制。

## 結果

### M1 集中度（迷思前提：**成立且大幅強化**）
- 2330 市值：**NT$1.68 兆（2010）→ 63.4 兆（2026-07），成長 37.7 倍**。
- 權重近似（central anchor）：**5.4%（2010）→ ~36%（2026）**；年度軌跡 2015≈10.8%、2020≈21.4%、2024≈28.4%、2025≈33.3%、2026≈37.7%。
- 公開資訊佐證同方向（~16-18%→~28%→~30-38%）。**集中度確實從「一角」變成「三分之一以上」**，且此 proxy 若考慮除數成長，早年權重應更低、上升更平緩，但方向不變。

### M2 傳導（同日成立、隔日被誇大）
| 門檻 | N | 同日 P(TWII跌) | 同日平均 TWII | 同日 vs 非事件 | 隔日 T+1 P(跌) | 隔日平均 | 隔日 vs 非事件 |
|---|---|---|---|---|---|---|---|
| **-3%** | 98 | **98.98%** | **-2.62%** | z=10.7, p<1e-4；Welch t=-16.3, p≈0 | 43.9% | +0.078% | z=-0.35, p=0.73；t=0.13, **p=0.90（不顯著）** |
| **-5%** | 15 | **100%** | **-4.22%** | z=4.24, p=2e-5；Welch t=-6.74, p=9e-6 | 40.0% | -0.21% | z=-0.44, p=0.66；t=-0.32, **p=0.75（不顯著）** |

- **同日**：台積電重跌，大盤幾乎必跌、且平均跌幅可觀（-3% 事件 → 指數 -2.62%；-5% 事件 → 指數 -4.22%）。極度顯著。
- **機械 vs 實證**：若 2330 權重 ~0.35，純機械貢獻約 = 0.35×(-3%) = **-1.05%**；實際指數 -2.62% **深於**純機械 → 其餘 ~1.6pp 是**真實的全市場共同下跌**（其他股票也跟著跌），不是純算術。
- **隔日 T+1**：事件次日指數下跌機率（43.9%）甚至**略低於**平常（45.6%），平均報酬轉為**微正**（+0.078%），統計上**與平常無異**。「隔天繼續生病」的方向性拖累**不成立**——市場當日已把壞消息定價完，隔日略偏（不顯著）反彈。

### M3 β（強共動 + 下跌不對稱，但無極端尾部放大）
- 全期 **β=0.537**（HAC t=34.5，R²=0.66）。**β >> 機械權重 ~0.35** → 證實共動超出台積電自身的指數份額，是真實的全市場「感冒」。
- Rolling β 從 2014 的 ~0.35 升到 2025-26 的 **~0.70**（近權重上限的兩倍），市場對台積電的敏感度隨集中度上升而**顯著增強**。
- **下跌 β=0.645 > 上漲 β=0.482**，不對稱**顯著**（z=3.59, p=0.0003）：下跌時大盤跟得比上漲時更緊。
- 但**極端大跌的額外放大**（-3% dummy 交互項 coef=+0.23）**不顯著**（t=1.60, p=0.11）→ 不對稱是一般性的「跌時共動較強」，並非特有的「大跌恐慌放大器」。

### M4 波動傳導（**成立，且顯著且持續**）
| 門檻 | N | 事件後 fwd-5d RV（年化）| 非事件 | 倍數 | 檢定 |
|---|---|---|---|---|---|
| **-3%** | 98 | **24.2%** | 14.2% | **1.70×** | Welch log-RV t=6.27 p≈0；MW p≈0 |
| **-5%** | 15 | **32.3%** | 14.4% | **2.25×** | Welch log-RV t=4.17 p=9e-4；MW p=3e-5 |

- 台積電大跌後，大盤**接下來一週的波動明顯放大**（-3% → 1.70 倍；-5% → 2.25 倍），高度顯著。這是迷思中「重感冒」最實質、最持續的部分。

## VERDICT：**部分成立（partially true），但需拆開看**

1. **「感冒」在當日與波動面是真的**：台積電重跌，大盤當天幾乎必跌且跌幅可觀（同日），且**接下來一週波動放大 1.7–2.2 倍**（M4）——這兩點**強力支持**俗諺。
2. **同日下跌有相當比例是機械算術**（2330 佔指數 ~35%），但 β=0.54 > 0.35 證實**確有超出機械份額的全市場共同下跌**，所以「重感冒」不是純粹的指數加權假象。
3. **「隔天還在生病」是迷思**：市場當日就把壞消息消化完，隔日方向上與平常無異、甚至略偏（不顯著）反彈——**方向性次日拖累不成立**。
4. **集中度前提成立且大幅強化**：權重從 ~6% 升到 ~36%，且 rolling β 同步從 ~0.35 升到 ~0.70——**這句俗諺在今天比十年前更貼切**。
5. 下跌 β 不對稱顯著，但**極端大跌的額外恐慌放大不顯著**——「跌時共動更緊」是一般現象，非大跌獨有。

**綜合**：迷思在「同日方向 + 一週波動」成立，在「隔日方向拖累」被誇大；且應誠實區分機械成分與真實外溢。

## 限制（誠實揭露）

- **M1 權重為近似**，非官方 TWSE 指數權重；常數除數假設會**誇大**上升幅度（真實上升更平緩），僅絕對市值成長為無假設證據，權重軌跡以公開資訊佐證方向。股數用當前常數，早年實際股本略小。
- **-5% 事件樣本僅 N=15**，隔日與波動檢定的 power 有限；-5% 的隔日/尾部結論宜視為 suggestive，-3%（N=98）較穩健。同日 15/15 全下跌的 asymptotic proportion z-test 宜以 Fisher exact / permutation 補強（Codex CONDITIONAL_PASS nice-to-have，發佈前若強調 -5% 再補）。
- **M4 forward 5 日 RV window 高度重疊**（相鄰事件日的 T+1..T+5 窗互相覆蓋），Welch / Mann-Whitney 的 p-value 會偏樂觀；波動放大方向穩健（ratio 1.70/2.25 + bootstrap CI 不含 1），但精確顯著性宜以 block bootstrap 或 `log(fwd_rv) ~ event_dummy` 的 HAC 迴歸重估（Codex CONDITIONAL_PASS nice-to-have）。
- **downside/upside β 差異的 z-test 為獨立估計近似**，作描述性證據可，最正式的不對稱檢定應改 pooled HAC interaction `r_tsmc × I(r_tsmc<0)`（Codex CONDITIONAL_PASS nice-to-have）。
- **同日傳導含機械成分**，不可解讀為純粹的「情緒外溢」；已用 β vs 權重的比較做部分分離，但未做逐日的成分股分解（可為後續方向）。
- **未控制共同市場因子**（如美股隔夜、費半、匯率）；台積電大跌常與全球科技股同步下跌，部分「傳導」可能反映共同外生衝擊而非 2330→大盤的單向因果。本實驗為**條件關聯 event study，非因果識別**。
- yfinance 非 time-travel 資料源；已存 snapshot CSV 供復現，但未來重抓可能因 corp-action backfill 微幅變動。
