# K1400: 退休族房貸決策 — 一次還清 vs 繼續繳 vs 還一半的 30 年提領模擬

## 動機

60 歲帶房貸退休的人，常見三選一：

- **A 一次還清**：手上現金扣掉房貸餘額，剩下做退休資產
- **B 繼續繳**：保留現金做退休投資，每月用提領支付房貸
- **C 還一半**：折衷

坊間試算通常用「投資年化 6% vs 房貸利率 2.2%，B 期望值高，所以選 B」這種點估算，忽略：

1. **報酬順序風險（sequence-of-returns risk）**：退休早期遇空頭 + 還在每月提領，破產機率被低估
2. **波動拖累**：算術平均 vs 幾何平均的差，會吃掉預期報酬
3. **結果是分布不是單點**：6% 是中位數附近，不是保證
4. **流動性結構**：A 把流動性換成不可逆的「房貸消除」，B 留住流動性但承擔提領壓力

VolPred 角度：把這三個策略放在歷史 + bootstrap 模擬下，比較 P(破產)、終值分布、worst-case，而不是比較期望值單點。

## 方法

### 資料

- TWII 台股加權指數月度收盤，1997-07 到 2026-05（~347 月，含 1997 亞洲金融、2000 網路泡沫、2008 海嘯、2020 COVID、2022 升息）
- 來源：`paper/taiwan-vt/data/_twii_1997_2007_snapshot.csv` + `paper/taiwan-vt/data/0050_tw_twii_*.csv`

### Block Bootstrap

- 月度 log returns
- Block size = 12 個月（捕捉年內 vol clustering）
- 模擬 10,000 個 30 年（360 月）path
- seed = 42

### 退休情境參數（baseline）

- 退休年齡 60，模擬 30 年
- 退休總資產 1000 萬（現金 / 投資 / 流動）
- 房貸餘額 300 萬，剩 15 年，年利率 2.2%（台灣 2026 主流）
- 月供（等額本息）≈ 19,635 元
- 月生活費（不含房貸）：30,000 元
- 年通膨 2%（生活費 inflate，房貸月供固定名目值）

### 三策略

| | 投資組合初值 | 月提領（前 15 年） | 月提領（後 15 年） |
|---|---|---|---|
| A 一次還清 | 700 萬 | 30,000 | 30,000（含通膨） |
| B 繼續繳 | 1,000 萬 | 49,635 | 30,000（含通膨） |
| C 還一半 150 萬 | 850 萬 | 39,818 | 30,000（含通膨） |

### Lookahead policy

每月：

1. 月初 portfolio
2. 月底套用該月 return（bootstrap sample）
3. 月底提領該月所需金額
4. 若 portfolio < 0 → 破產，記破產月，path 結束

無預知資訊；報酬與提領 timing 一致。

### Sensitivity

房貸利率 baseline 2.2%；額外跑 1.5% / 3.0% 兩組看 robustness。

## 成功標準

1. 三策略破產率明確排序（不能 tie within MC error）
2. 終值分布 5th / 50th / 95th percentile 全列
3. Worst-case 起點對比歷史（哪一年退休最糟）
4. 至少 2 張圖（path envelope + 破產率比較）

## 防錯

- 月度 returns 用 log return → 連乘正確
- 提領要扣 inflation-adjusted 名目值
- 房貸月供 15 年後歸 0
- bootstrap seed 固定 = 42
- portfolio 算到 < 0 即破產（不允許負餘額借錢繼續）
