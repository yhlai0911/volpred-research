# K1409 — 高股息 ETF「月月配 1 萬」規劃的 block-bootstrap 模擬

## 動機

台灣爆紅的退休現金流規劃：用 3 檔台股高股息 ETF（**0056、00878、00919**）
配息月份錯開，排成「月月領約 NT$1 萬」。本實驗用**真實歷史資料 + bootstrap
模擬**誠實檢驗這個規劃的風險：月配息與本金淨值的分布區間、每月領 1 萬的
達標機率、下檔風險，以及圖中隱含的 ~9.7% 現金殖利率是否過度樂觀。

## 組合（固定張數，1 張 = 1000 股）

| ETF | 張數 | 近期收盤 | 本金（市值） |
|---|---|---|---|
| 0056.TW | 10 | 50.20 | 502,000 |
| 00878.TW | 23.8 | 30.76 | 732,088 |
| 00919.TW | 12.8 | 29.01 | 371,328 |
| **合計** | | | **1,605,416** |

> 本金約 **161 萬**（抓取日 2026-05-29 實際收盤計）。與圖中宣稱約 123.5 萬
> 差距較大，主因抓取當下三檔股價（特別 0056 約 50 元）高於圖製作時 —— 以
> 實際算出值為準，不回套圖中數字。目標每月領 1 萬 → 年領 12 萬 → 對 161 萬
> 本金的隱含現金殖利率約 **7.5%**；圖中以 123.5 萬計為 9.7%。本實驗統一以
> 圖中宣稱的 **9.7%** 作為「隱含殖利率」基準比對（最嚴格、最有利於該規劃的
> 口徑），檢驗其是否過度樂觀。

## 資料（真實，研究誠實）

- 來源：yfinance。價格用 `auto_adjust=False` 的**原始收盤**（只算 price return，
  不含配息還原）；配息用 `Ticker.dividends`（除息日 + 每股配息），**另計現金流**，
  與價格報酬明確分開、**不重複計**。
- 抓取日：2026-05-29。各檔資料跨度：
  - 0056.TW：2007-12-26 ~ 2026-05-29（價格 5570 筆；配息 26 筆，2008 起）
  - 00878.TW：2020-07-20 ~ 2026-05-29（價格 1442 筆；配息 22 筆，2021 起）
  - 00919.TW：2022-03-23 ~ 2026-05-29（價格 1235 筆；配息 21 筆，2022 起）
- 快取於 `data/`（`*_close.csv` / `*_div.csv`），可離線重跑。

## 方法

### 1. 共同重疊期母體

三檔歷史長度不同，受 00919（yfinance 價格資料 ~2022-10 起）限制，
price-return bootstrap 母體取**三檔共同重疊期 = 2022-11 ~ 2026-05（43 個月）**。

### 2. 價格報酬：joint block bootstrap

- 以**月**為單位、block size = 3 個月，從共同重疊期的月價格報酬抽樣。
- 三檔**共用同一組 block 起點** → 保留跨資產同期連動 + 波動聚集 + 時序結構。
- 重組未來 **36 個月**路徑；固定張數 → NAV = 初始市值 × ∏(1 + 月報酬)。

### 3. 配息：保留真實除息月曆 + 金額 bootstrap

「月月配」是**日曆結構**（季配錯開），不是隨機事件 —— 三檔在重疊期的實際
除息月份合計覆蓋 **12 個月中的 11 個**（僅 4 月無人配息）：

| ETF | 重疊期除息月份 | 重疊期配息次數 |
|---|---|---|
| 0056.TW | 1, 4, 7, 10 | 12（季配） |
| 00878.TW | 2, 5, 8, 11 | 14 |
| 00919.TW | 3, 6, 9, 12 | 12 |

> 三檔合計除息月份覆蓋 **12 個日曆月全滿**（季配三檔錯開，剛好填滿 1–12 月）。

因此配息模擬**保留每檔真實的除息日曆**（哪個月由哪檔配是固定的），只對
**每股配息金額**做 bootstrap（從該檔重疊期實際每次配息的母體抽，with
replacement）。

> **為何不對「整月配息」直接 block bootstrap**：那會打亂日曆對齊、虛構出
> 大量本不存在的 0 配息月（artifact）。原始 v1 設計即犯此錯（block bootstrap
> 把配息與報酬整月綁抽，產生大量假的 0 配息月），已修正為本設計。

### 4. 隨機性與防錯

- 固定 `seed = 20260530`；`N_SIM = 5000`。
- 價格報酬與配息現金流分開累加，**無配息重複計**。
- 無 lookahead：bootstrap 只用歷史母體重組未來，未用任何未來資訊。
- 非循環 block bootstrap 的標準邊界效應：block 起點 ∈ [0, n−3]，最後 1–2 個月
  的歷史月略微少被抽到（n=50、block=3 下）；非 bug，對整體分布影響極小。

2026-05-29 Codex 0.132.0 review：**CONDITIONAL_PASS** —— 配息重複計 / lookahead /

## 主要結果

執行：`uv run python experiments/k1409/k1409.py`（首次需 `--refresh` 抓資料）。
完整數值見 `k1409_results.json`。

### 月配息

| 指標 | 數值 |
|---|---|
| 除息日曆覆蓋 | **12 / 12 個月**（季配錯開填滿全年） |
| 有配息月 單月配息 中位數 | NT$9,216 |
| 有配息月 5% / 95% 分位 | NT$6,912 / NT$13,090 |
| **P(有配息月單月 ≥ 1 萬)** | **33.9%** |
| 平均月配息 中位數 | NT$9,418 |
| **P(平均月配息 ≥ 1 萬)** | **2.7%** |

### 淨值（本金約 161 萬，未含已領配息）

| 時點 | 中位數 | 5% 分位 | 95% 分位 |
|---|---|---|---|
| 36 個月 | 2,435,184 | 1,663,027 | 3,685,548 |

- 淨值 5% 分位相對本金：**+3.6%**（母體偏多頭，連 5% 分位都未跌破本金 ——
  這是資料限制造成的樂觀偏誤訊號，見下）。

### 下檔風險

| 指標 | 數值 |
|---|---|
| MDD（總財富路徑）中位數 / 5% 最壞 | −9.5% / −16.4% |
| 36 月總報酬 VaR5 / CVaR5 | +24.6% / +15.8% |

> 註：VaR5/CVaR5 為正，反映母體嚴重偏多頭（連 5% 最壞情境的 36 月總報酬仍
> 為正 +15.8%）—— 這正是資料限制造成的樂觀偏誤訊號，真實長空頭下不可能如此，
> 見下。

### 殖利率：隱含 vs 可實現

| 指標 | 數值 |
|---|---|
| 圖中隱含現金殖利率 | 9.7% |
| **模擬可實現殖利率 中位數** | **7.04%** |
| 5% / 95% 分位 | 6.67% / 7.40% |
| P(可實現 ≥ 隱含 9.7%) | **0.0%** |

> 對照：以抓取日真實 TTM（近 12 月）配息計，整組合現金殖利率約 **7.7%**，
> 與模擬中位數 7.0% 同量級，互相印證；兩者都遠低於圖中隱含 9.7%。

## Verdict

1. **「月月領 1 萬」達標機率**：
   - 季配錯開讓 **12 個日曆月全有配息**（三檔季配剛好填滿全年）。
   - 但「有配息的月份就能領滿 1 萬」的機率只有 **33.9%**（中位數 NT$9,216，
     略低於 1 萬）。
   - 以「**平均月配息**」（退休現金流的真正口徑）計，達 1 萬的機率僅 **2.7%**，
     中位數 **NT$9,418（約目標的 94%）**。**這個規劃在模擬裡幾乎不可能穩定
     達成「每月平均領滿 1 萬」**，多半略差一點。

2. **壞情境月配息**：有配息月的 5% 分位掉到 **NT$6,912**（約目標的 69%）。

3. **161 萬本金的淨值下檔**：母體偏多頭，36 個月後連 5% 分位淨值仍約 **166 萬
   （本金以上 +3.6%）**；總財富路徑 5% 最壞 MDD **−16.4%**。**這個「下檔幾乎不
   虧」的結果本身就是資料限制的警訊**：43 個月母體幾乎沒有像樣的長空頭，
   真實長空頭下淨值絕對會跌破本金。

4. **隱含 9.7% 是否過度樂觀**：**是，明顯高估**。模擬可實現殖利率中位數僅
   **7.04%**，達到 9.7% 的機率為 **0.0%**；真實 TTM 殖利率約 7.7% 也印證此結論。
   圖中隱含值高估約 **2.7 個百分點**。

5. **資料限制對結論的影響方向（全部偏樂觀）**：
   - 共同重疊期僅 43 個月、幾乎只經歷 2022 一次空頭 + 後續多頭 → bootstrap
     母體**嚴重偏多頭**，因此 VaR5/CVaR5 甚至為正、MDD 偏小、淨值 5% 分位
     不跌破本金。**真實長空頭下的下檔風險與斷配風險被顯著低估**。
   - 配息金額母體取自近年（高息政策積極期）；若未來配息縮水或斷配，模型未涵蓋。
   - 模型**未計**交易成本、二代健保補充保費、股利所得稅 → 實際可支配現金流
     會**更低**，達標機率比上述更差。

**一句話**：這個組合靠季配錯開能做到「全年每月都有錢進」，但「每月平均領滿
1 萬」在現實殖利率（~7%）下幾乎做不到（達標率僅 2.7%，平均差約 6%）；圖中
9.7% 隱含殖利率明顯偏樂觀（實際約 7%），加上母體嚴重偏多頭，真實下檔與斷配
風險被低估。
