# Paper 10 — Reproduction Scripts

**Paper**: The Crypto Fear Channel — Asymmetric, Tail-Concentrated, and Regime-Dependent Volatility Spillover from Bitcoin to Equity Markets
**Compliance**: Part of item (2) of the 5-item self-contained paper folder checklist (`docs/paper-guide.md`).
**Last updated**: 2026-04-17

This directory documents how to reproduce every numerical claim that appears in
the Paper 10 body `.tex`. Per CLAUDE.md three-way consistency rule, the
numbers printed in the body MUST match the JSON artifacts regenerated by the
scripts below, or a reconciliation path (errata / `reproduce_report.json`)
must be declared.

Per K1246 scope, the canonical scripts continue to live under
`experiments/kXXXX/`. This directory does **not** duplicate them — it provides
a thin coordination layer that invokes the canonical scripts in order. This
respects the research-repository convention that an experiment is a
self-contained unit under `experiments/kXXXX/`, and avoids the
scripts-drift anti-pattern where the paper copy gradually diverges from the
experiment copy.

## 1. Entry points (canonical paths)

Each Paper 10 section is reproduced by invoking the corresponding canonical
entry point in `experiments/kXXXX/`:

| Paper 10 section | K source | Canonical entry point                              | Output JSON                                           |
|------------------|----------|----------------------------------------------------|-------------------------------------------------------|
| §5.1–§5.3, §6.1–§6.2, §7.1 | K1025    | `experiments/k1025/k1025.py`                       | `experiments/k1025/k1025_results.json`                |
| §5.1 baseline     | K639     | `experiments/k639/k639_crypto_equity_vol.py`       | `experiments/k639/k639_results.json`                  |
| §5.1 asymm confirm | K746b   | `experiments/k746b/k746b_bitcoin_vix_fixed.py`     | `experiments/k746b/k746b_bitcoin_vix_fixed_results.json` |
| §6.5 Table 3 (NULL) | K1241 | `experiments/k1241/k1241.py`                       | `experiments/k1241/k1241_results.json`                |

All four scripts are self-contained: they fetch data via `yfinance`, set
`seed=42`, and write the named JSON alongside themselves. No command-line
arguments required.

## 2. Running a single section

From the repository root:

```bash
# §5–§7 primary framework (long-running: ~5–10 min including spillover rolling)
uv run python experiments/k1025/k1025.py

# §5.1 baseline (short: <2 min)
uv run python experiments/k639/k639_crypto_equity_vol.py

# §5.1 asymmetric confirmation (short: <2 min)
uv run python experiments/k746b/k746b_bitcoin_vix_fixed.py

# §6.5 pooled GARCH-X NULL (long-running: ~5 min including rolling φ window)
uv run python experiments/k1241/k1241.py
```

Each script is deterministic given `seed=42` and yfinance response integrity.
If yfinance returns different bars on a re-run, the results JSONs will differ
marginally. This is expected (and is documented in `data_sources.md` §4
"Risks to long-run reproducibility").

## 3. Full reproduction (planned)

Planned for main-thread build, **not yet created by this draft**:

```
paper/crypto-fear-channel/
├── reproduce.py                      # <-- planned; not part of K1246
└── scripts/
    ├── README.md                     # <-- this file (K1246 draft)
    └── reproduce_report.json         # <-- planned; produced by reproduce.py
```

The planned `reproduce.py` will:

1. Invoke the four canonical entry points in §1 in sequence (K1025 → K639 →
   K746b → K1241).
2. Load the resulting JSONs.
3. Compare each canonical number against the corresponding hard-coded number
   in the Paper 10 body `.tex` (using an externally-supplied manifest of
   "body claims").
4. Write `reproduce_report.json` with:
   - `pass` / `fail` / `tolerance-within` per claim
   - `observed` vs `paper_value`
   - `tolerance` (absolute; default $10^{-3}$ for coefficients, $10^{-6}$ for
     F-statistics, exact match for p-values in scientific notation)
5. Exit with non-zero status if any claim diverges outside tolerance.

`reproduce_report.json` then becomes the canonical artifact for the
paper-guide three-way consistency check (rule (a) fix script, (b) fix paper,
(c) errata — see `docs/paper-guide.md` section "腳本/資料/論文數字必須三方一致").

## 4. Why no `run_kXXXX_*.py` wrappers?

The K1246 task brief initially suggested individual wrappers such as
`run_k1025_quantile_regression.py`, `run_k639_dy_spillover.py`, etc. K1246
deliberately does **not** create these wrappers, for three reasons:

1. **Naming fidelity**: Each K script is a single script covering the full
   experiment (Granger + QR + DY + forecasting for K1025, bidirectional
   vol linkage for K639). A thin wrapper named after one analysis (e.g.
   "quantile_regression") would mislead about K1025's actual scope.
2. **Drift risk**: Wrappers create a second maintenance surface. When
   K1025 internals change, wrappers must be updated in lockstep.
3. **Paper-guide rule**: `docs/paper-guide.md` allows "完整程式在
   `experiments/kXXX/`" with a pointer from `scripts/README.md`. That is
   exactly the pattern we use here.

When the main-thread builds `reproduce.py`, that single coordinator script
will satisfy the one-click-reproduction intent without creating four
duplicate wrappers.

## 5. Dependencies

Python packages (see project `pyproject.toml`):

- `yfinance>=0.2.40` (data retrieval)
- `numpy`, `pandas`, `scipy`, `statsmodels` (estimation and tests)
- `arch` (K639 GARCH fit only; K1241 uses pure-numpy MLE)
- `matplotlib` (K1241 figure outputs; headless `Agg` backend)

No paid APIs, no compiled extensions. All scripts run on stock `uv` Python
environment.

## 6. Reproducibility caveats

- **Yahoo Finance data drift**: See `data_sources.md` §4. The raw data is
  not versioned; long-term (5-year) reproducibility depends on Yahoo
  continuing to serve the three tickers with their current historical
  series.
- **Optimization starts**: K1241 uses multi-start L-BFGS-B + Nelder-Mead
  polish with hand-chosen seeds (no randomness). K1025 Granger / QR / DY
  are all closed-form or deterministic at fixed seed.
- **Sub-period boundaries**: K1025 uses 5 sub-periods; K1241 uses 3
  sub-periods (K1133 convention). Both are hardcoded; if either changes,
  the corresponding paper body numbers must be regenerated.
