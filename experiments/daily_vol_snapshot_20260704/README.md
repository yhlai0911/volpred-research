# daily_vol_snapshot_20260704 — 美台隱含波動率背離快照

**類型**：daily_article 佐證資料（描述性市場快照，非預測模型 / 非回測）
**As-of**：2026-07-04（台灣時間；NFP 2026-07-02 作時間錨，非主軸）

## 動機
2026-07-02 非農就業數據對美股是非事件（VIX 反跌、標普持平）。真正有訊息的是把台美隱含與已實現波動率攤開對照後的結構差距：台指 VIX 是美股 VIX 的 2.34 倍（窗口 96.5 百分位）。

## 方法
- 隱含波動率：美股 VIX / Nasdaq VXN（Yahoo Finance）、台指 VIX（VIXTWN，台灣期交所日資料）
- 已實現波動率：20 日對數報酬標準差 × √252（台股加權指數、SPY）
- 波動率溢價 VRP = 隱含 − 已實現（20 日年化）
- 百分位窗口：2025-12-01 ~ 2026-07-03（約 7 個月，VIXTWN 歷史起點所限，屬近期體制內比較）
- 描述性統計，無 signal / lag / 回測（無 lookahead 風險）

## 主要發現
- 台美 VIX 價差 21.67 點（92.3 百分位）、比值 2.34x（96.5 百分位）
- 拆解 VRP：台股 VRP +3.74（VIXTWN 37.82 vs RV 34.08%）；美股 VRP −1.83（VIX 16.15 vs RV 17.98%）
- 背離大半來自「真實波動」差距（台股 RV 34% vs 美股 18%），非純恐慌溢價
- 美股 VIX 低於自身已實現波動 → 選擇權偏便宜 / 定價偏低
- 台股加權指數過去一週 +4.96%、收 46780（距 5 年高點 47741 僅 −2.01%），高檔區仍高波動
