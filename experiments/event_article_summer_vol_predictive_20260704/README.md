# event_article_summer_vol_predictive_20260704

**類型**：event_article / current-affairs（reader-facing，audience=general）
**觸發 hook**：2026-07-04 美股獨立紀念日長假、VIX 15.81 低檔平靜盤。
**日期**：2026-07-04（台灣時間）

## 研究問題

描述性事實「7 月是全年最平靜月份」已知（feed 舊文「波動率季節性：最強月=3月，最弱=7月」）。
本文檢驗**預測性**問題（differentiated conclusion class）：
**夏季（6-7 月）低波動，是否預示秋季（9-10 月）波動放大？**（即民間「暴風雨前的寧靜」直覺是否成立）

## 數據

- `^VIX`（隱含波動率）+ `^GSPC`（21 日年化已實現波動率），yfinance，2005-01 ~ 2026-07-03
- 21 個完整年度（夏季+秋季均有觀測）
- seed=42（本分析無隨機程序，僅描述統計 + Pearson/OLS）

## 方法與無前視保證

- 夏季 = 6-7 月 VIX 月內平均；秋季 = 同年 9-10 月平均。夏季**完整早於**秋季，無前視。
- 非交易策略，無 signal.shift 需求（純 contemporaneous 季節分組 + cross-year 相關）。
- Pearson r + Spearman + OLS；calm/hot 夏季以中位數切分。

## 主要發現（results.json）

| 項目 | 數值 |
|---|---|
| 最平靜月 / 最兇月（VIX 月均） | 7 月 17.23 / 10 月 21.20 |
| 夏季→秋季 VIX 相關 | Pearson r=**+0.629** (p=0.0022), OLS R²=0.396 |
| 平靜夏季後秋季均值 vs 火熱夏季後 | **16.22 vs 24.77** |
| 夏季 RV→秋季 RV | r=+0.425 (p=0.055, borderline) |
| 夏季 VIX<15（真正平靜）共 8 年，秋季最高 | 2015 的 20.5（其餘 <19）；**無失控** |
| 真正「夏平→秋暴」離群 | 2008（夏23→秋46）、2011（夏19→秋35），但兩者夏季本已偏高 |
| 年度最大 VIX 尖峰落 8-10 月比例 | 22.7% < 均勻 null 25%（8 月 4 次最多但多短暴，9 月 0、10 月 1） |
| 2024 案例 | 7 月均 14.47 → 8/5 尖峰 38.57 → 秋季回落 18.94（短暴非秋暴） |
| 當前（2026-07-03） | VIX 15.81（20 日均 18.12） |

## 結論

**波動率是「延續」不是「反轉」**。平靜夏季通常接平靜秋季（r=+0.63）；「暴風雨前的寧靜」對 summer→autumn 整季水準而言是迷思。
兩層真相：(1) 整季波動水準延續；(2) 短暫尾部尖峰**不挑季節**（8 月偶爾咬人但急來急去）。
Actionable：別因 VIX 低就賭季節性風暴（跟趨勢對作）；尾部保護當常設配置而非看月曆；該警戒的訊號是夏季 VIX 偏高、非偏低。
