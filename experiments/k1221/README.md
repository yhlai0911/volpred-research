## Key blockers identified

1. **main.tex does not yet cross-reference Appendix A / K1200** (K1218 draft
   exists but not yet cherry-picked into `main.tex`). This is the single
   highest-ROI submission fix since it converts the `7d35418b` errata commit
   from an internal note into a reviewer-visible defence.
2. **Table 1 0050.TW OOS start date mismatch (2019/12 vs actual 2021/01)**
   — DIV-2 from `reproducibility_audit/`. 1-line fix in main.tex.
3. **No `data_sources.md` section documenting Zenodo / LFS plan** for the
   TAIFEX tick data. FRL accepts "data available on request" for proprietary
   sources, but journal replication-package rules are tightening; a 2-line
   contact-author clause is recommended.

WARN items (do not block submission but polish the package):
- `reproduce.py` does not programmatically verify the K1200 defensibility band
  (MINOR_DIVERGENT); the match check is against K880v2, not K880. If a
  reviewer reruns, they will see the divergent-from-v2 message with no
  context. Suggested: pin reference to K880 canonical + note MINOR_DIVERGENT
  band is acceptable.
- `paper/prg-periodic-garch/data/` folder is not created; all raw data lives
  outside the paper tree. `data_sources.md` covers this adequately, but
  journal reviewers sometimes expect a `data/` stub with a pointer README.
- Figure scripts (standalone .py) do not exist in `paper/prg-periodic-garch/`;
  figures are regenerated by the full experiment scripts. Acceptable per
  `docs/paper-guide.md` but a short `figures/README.md` explaining the
  soft-link mapping would improve reviewer experience.
