# K1394 — 兒少投資帳戶的複利幻覺：波動拖累與報酬順序風險

## 動機

近期台灣在討論兒少版個人投資儲蓄帳戶（TISA）：政府或家長每月幫下一代
定額投入、靠長期複利累積。坊間幾乎所有試算都用「平滑固定報酬率」
（6%、8%）畫一條光滑的複利曲線。真實市場是波動的，這種試算會系統性
誤導讀者。VolPred 是波動率研究平台，本實驗把「波動」放回這個故事。

## 研究問題

用 SPY 真實歷史回測「每月定額、持有 18 年」的定期定額（DCA）策略，
量化三件平滑複利試算沒講的事：

1. 真實 18 年路徑是顛簸的，不是教科書的平滑曲線。
2. 波動拖累（volatility drag）：幾何（複利）年報酬 < 算術平均年報酬。
3. 報酬順序風險（sequence-of-returns risk）：同一套策略從不同歷史
   起點開始，18 年後的結果是一個分布，不是單一數字。

## 資料

- 來源：`paper/garch-x-vix/data/spy_vix_qqq_eem_fez_2000-2026.csv`
- 欄位：`spy_adj_close`（SPY 調整後收盤，含股息再投資）
- 期間：2000-01-03 至 2026-05-19，6,644 個交易日，無缺值
- 月末序列：317 個月末值（取每月最後一個交易日）

## 方法

- **月頻 DCA**：每月月末投入固定 5,000 元，以該月末調整收盤價買進份額。
- **持有期**：18 年 = 216 個月。
- **rolling 起點**：在 317 個月末值內跑所有可行的 18 年連續視窗
  = 317 − 216 + 1 = **102 個起點**，得到 102 個 18 年結果。
- **金額加權年報酬**：對每個視窗解 money-weighted IRR（現金流：投入在
  t=0..215、終值贖回在 t=215），再年化。
- **實質終值**：名目終值除以 (1.02)^18，給保守購買力下限視角。
- **波動拖累**：用 25 個完整日曆年（2001-2025）的年報酬序列，
  算術平均年報酬 − 幾何平均年報酬。
- **坊間對照**：每月 5,000 元、固定月利率 6%/12、216 個月的平滑終值。

## 防錯

- **無 lookahead**：月末投入時序明確 — 第 i 筆投入只承受其後月份的
  價格變化；估值在最後一筆投入的同一月末，最後一筆持有 0 個月（標準
  保守設定）。代碼中時序定義寫在 `simulate_dca` docstring。
- **seed**：固定 `seed=42`（本實驗為純歷史回測，seed 僅作規範保留）。
- **公平**：102 個 rolling 視窗用完全相同的 DCA 口徑。
- **資料診斷先行**：先檢查期間、樣本數、缺值，再計算。

## 主要結果

| 指標 | 數值 |
|---|---|
| 算術平均年報酬（2001-2025 完整年） | 10.36% |
| 幾何平均年報酬 | 8.76% |
| **波動拖累** | **1.59%/年 ≈ 159 bp** |
| 年報酬標準差 | 17.81% |
| 18 年名目終值（min / median / max） | 241.6 萬 / 331.9 萬 / 466.1 萬 |
| 18 年實質終值（扣 2% 通膨，min / median / max） | 169.2 萬 / 232.4 萬 / 326.4 萬 |
| 金額加權年報酬（min / median / max） | 8.37% / 11.43% / 14.62% |
| 坊間「平滑 6%」18 年終值 | 193.7 萬 |
| 總投入（5000×216） | 108.0 萬 |

- 最差起點 2002-04 → 2020-03（恰好在 COVID 崩盤收尾）：終值 241.6 萬。
- 最佳起點 2008-06 → 2026-05（金融海嘯入場、長多收尾）：終值 466.1 萬。
- 最佳 / 最差倍數差約 1.93 倍 — 同策略，差在出生年。

## Caveats

- SPY 含股息再投資，未扣交易成本與管理費。
- 歷史回測；US 大盤是 survivorship-favourable 市場，台灣或其他市場
  結果分布會更寬、更偏。
- 實質終值以期末一次折現，為保守購買力視角。
- rolling 視窗高度重疊（相鄰起點差一個月），分布極端值由少數獨立
  18 年段落驅動，非獨立樣本 — 視為情境涵蓋而非統計推論。
