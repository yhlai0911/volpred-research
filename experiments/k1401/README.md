# K1401: GDP Q1 Second Estimate Event Study

## 摘要

分析 BEA 每年 5 月底發布「Q1 GDP 第二估」時，VIX 與 SPY 在事件窗口 [-5, +5] 交易日的反應模式。
涵蓋 2001–2025 年共 25 次發布，重點測試三個假說：

- **H1**: 發布前一週 VIX 是否顯著上升（不確定性聚積）
- **H2**: 宣布後 VIX 是否次日下降（不確定性解除）
- **H3**: GDP 修正方向（上修 vs 下修）是否造成不對稱 VIX 反應

## 動機

BEA Q1 GDP 第二估定期於每年 5 月底發布（2026 年為 05/29），為重要總體數據事件。
搭配當前關稅／停滯性通膨環境，本實驗提供事件驅動文章（05/27 預覽稿）的量化基礎。

## 方法論

| 項目 | 設計 |
|------|------|
| 事件 | BEA Q1 GDP 第二估，2001–2025 |
| 事件窗口 | [-5, +5] 交易日 |
| 市場數據 | yfinance SPY + ^VIX，2000-01-01 起 |
| 統計檢定 | Harvey/Bonferroni 多重比較校正，k=3，α_adj=0.0167 |
| Seed | 42 |
| Lookahead | 無（純歷史事件研究） |
