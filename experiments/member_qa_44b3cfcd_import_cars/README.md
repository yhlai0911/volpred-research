# member_qa_44b3cfcd_import_cars

## 問題
會員 yaoxk1431 提問：「看到台灣路上進口車比例越來越高，這跟台灣經濟變遷有關，請幫我整合此資訊，推薦可以買的股票並說明投資理由 2000 字 並生成圖表」

## 資料來源
- 進口車比例歷年數據：交通部公路總局 / 中華民國海關 / 台灣區車輛工業同業公會 (TTVMA) / U-CAR / SiCAR / 經濟日報統整
- 個股財務數據：yfinance（2026-05-26 抓取，股價 / 市值 / 本益比 / 殖利率 / EPS）
- 3 年股價歷史：yfinance 2023-01-03 ~ 2026-05-25（815 trading days）

## 主要發現
1. 進口車滲透率 10 年從 ~21% 增至 ~50%
2. 但個股 3 年表現嚴重落後 TWII（^TWII +207%；2227 -70%、9941 -39%、2207 -15%、2204 +24%）
3. 經濟學機制：中產購買力上升、消費升級、貿易自由化（ECFA / 關稅減讓）、廠商產品策略改變（國產車廠改賣進口豪華）

## 投資啟示
- 「行業大趨勢」不必然等於「個股 alpha」— 進口車滲透率攀升的最大受益者反而是國際品牌母公司，不是台灣經銷代理
- 和泰已用 Lexus 進口豪華補上 Toyota 國產失血，但毛利率受限（7%）
- 裕融的金融模式較不受製造端 disruption，殖利率 6.01%、本益比 9.9 屬於估值穩定區
- 裕日車 EPS 嚴重衰退（trailing EPS 僅 1.3，PE 37x），業務面臨結構性挑戰
