# K1580 — 年度等權再平衡 vs 買進持有 vs 大盤指數（台灣 + 美國 + 全球，含分時期）

## 動機

驗證一個自創策略：**年度等權再平衡（annual equal-weight rebalancing）**。
規則 = 每年第一個交易日，計算組合內 N 檔的總淨值，平均分配（每檔目標 = 總額 / N），
高於目標賣到目標、低於買到目標，回到等權；持有一年後再重複。

問題：這方法是否真的優於「買進持有同籃子」與「直接買大盤指數」？國內外、跨年代是否一致？

## 方法

- **下載下限** 1990-01-01；各籃子實際起點 = 「全員（含對照）都有資料的最早日」自動決定（`_basket_window`）。
- **資料**：yfinance `Close`（`auto_adjust=True`，已還原配息/拆股）。
- **6 籃子**（含 2 個台灣對照口徑 0050/^TWII）：
  | 籃子 | 標的 | 對照 | 存活者偏差 |
  |---|---|---|---|
  | TW_large_caps | 台灣 10 大型股 | 0050.TW（經 `clean_tw50_data` 修拆股） | 有 |
  | TW_large_caps_TWII | 同上 | ^TWII（price-only，歷史更長到 2001） | 有 |
  | US_large_caps | 美國 10 大型股 | SPY | 有 |
  | US_sector_ETFs | 9 檔 SPDR 產業 ETF | SPY | 降低（仍有集合選擇） |
  | US_multi_asset | SPY/TLT/GLD/VNQ/DBC | SPY | 無個股偏差 |
  | Global_country_ETFs | 9 國 iShares | ACWI | 無個股偏差 |
- **三條腿**：年度等權再平衡 / 買進持有（期初等權後不動）/ 大盤指數買進持有。同期間、同起點、同 initial（1,000,000）、同成本慣例。
- **交易成本**：no_cost / 台股 30bps / 美股 10bps（單邊，charge 在成交名目）。
- **顯著性**：對每日 (rebal − BH) 報酬差做 moving-block bootstrap（block=21、n_boot=5000、**seed=42**）取年化差 CI95；分時期另跑短窗 bootstrap（標 power 低）。
- **分時期**：7 個 regime（網路泡沫 / 2003-07多頭 / 金融海嘯 / 2010s長多 / COVID / 2022升息輪動 / 2023-24 AI大型股）。

### 防錯（研究誠實）
- **無 lookahead**：再平衡採「理想化同日收盤(MOC)執行假設」——以該年首個交易日收盤價計算淨值並回到等權，新權重不乘同日報酬（非 lookahead alpha），但屬理想化執行假設，非保證成交價。
- **建倉成本計入績效**：`_metrics` 以 INITIAL（gross）為分母，rebal/BH/benchmark 一致。
- **再平衡成本 self-financing**：3 次 fixed-point 迭代求解（非近似）。
- **0050.TW 數據修復**：yfinance 把 2025-06-18 的 1:4 拆股只回溯到 2014-01-02 → 2014-01-02 假 -75% 報酬；用 `volpred.utils.clean_tw50_data`（external-data-sources skill 記載的 canonical fix）修回連續序列。
- **存活者偏差揭露**：個股籃子標 `survivorship=True`；ETF 籃子標「降低個股偏差但非完全無偏」。
- 固定 seed；單一籃子失敗不擋其他。

### 分時期（rebal − BH，年化 %/年；圖 fig_a 熱力圖）
- **危機/輪動年再平衡贏**：2008-09 金融海嘯（+0.0 ~ +7.5）、2022 升息輪動（+0.8 ~ **+21.7**，美股）→ 全籃子幾乎全正。
- **單邊大型股年再平衡輸**：2020-21 COVID 科技（美股 −17.3）、2023-24 AI 大型股（台股 −14.1、美股 −12.9）→ 修剪了狂飆的贏家（台積電、mega-cap tech）。

## 結論（NULL / 細緻版）

1. **長期報酬：年度等權再平衡 ≈ 買進持有，沒有穩健的再平衡 alpha** — 6 籃子差異全部統計不顯著（CI95 全含 0）。CAGR 點估計**混合但偏正**：6 籃子中 5 個 rebal CAGR 持平或略高（TWII +1.50、產業 +0.72、跨國 +0.47、美國大型股 +0.05、多資產 +0.04 %/年），**只有台股 0050 籃子 rebal 略低（−1.18%/年）**——因為買進持有那條腿被預先選中的 mega-winner（台積電）撐高（存活者偏差）。降低個股偏差的籃子（產業/多資產/跨國）方向與「diversification return」文獻一致（小幅正向），但皆不顯著。
2. **風險調整後 rebal ≥ BH**：多數籃子再平衡的最大回撤與波動低於買進持有，Sharpe 相當或更高（美國大型股 0.94 vs 0.86、MDD −37.6% vs −46.2%）。
3. **不是成本問題**：年度頻率交易極少，三種成本下 CAGR 幾乎不變。
4. **本質是「溫和反動量 / 再平衡紀律」策略**：輪動/均值回歸年佔便宜、單邊強勢年讓出動量；長期互相抵銷 → 與買進持有打平偏正。
5. **無任何籃子負總報酬**（11-32 年 CAGR 3%~16%）→「方法正常運作、長期獲利」屬實；但「優於買進持有」是 regime-dependent、長期接近打平，非無條件成立。
