## Findings

No source-level blocker found for the reported K1361 result.

The predictive regressions use explicit one-day lags:

```python
f"{source}_lag1": log_rv[source].shift(1)
```

The experiment also separates descriptive connectedness and stress/calm
correlation diagnostics from predictive lead tests.  This matters because the
strongest empirical pattern is contemporaneous stress correlation, not a robust
lagged transmitter result.

## Checks

- `SEED = 42` is fixed and used for bootstrap resampling.
- `K1361_results.json` is generated by the experiment script, not hand-filled.
- The README conclusion matches the JSON: 0 connectedness transmitter passes,
  1 of 8 lagged source-volatility tests clears `t >= 3`, and 8 of 8 stress
  correlation diagnostics rise.
- The result does not claim a trading strategy, causal spillover, or option
  pricing implication.

## Caveats

- yfinance adjusted-close proxies are survivorship-biased and cannot represent
  the full gaming / betting universe.
- Rolling stress/calm windows overlap, so the Welch and bootstrap diagnostics
  should be read as descriptive evidence, not independent event counts.
- FLUT and BTC calendar treatment is disclosed and should not be used for a
  stronger listing-history or continuous-calendar claim.

## Allowed Knowledge Claim

K1361 supports the narrow finding that public gaming / betting proxies behave
more like diversification sinks during market stress than like strong
volatility transmitters.  It does not support a robust ex-ante market turmoil
forecasting claim.
